## Данные и безопасность

Приложение автономно. Не передавать финансовые данные, не использовать внешние
OCR API или телеметрию. Тесты и CI используют только синтетические данные.
Пользовательские отчёты, журналы, книги, копии, пароли и ключи не добавлять в Git.
Не удалять пользовательские данные и не заменять существующие книги/копии.
Суммы — целые минимальные единицы, вычисления ставок — Decimal, без float.

## Проверки и изменения

Делать небольшие логические коммиты. Зависимости зафиксированы в uv.lock;
установка: uv sync --frozen. Не менять lock-файл без причины.
Основные проверки:

- uv run --frozen ruff check src tests tools
- uv run --frozen ruff format --check src tests tools
- uv run --frozen mypy src/personal_finance
- uv run --frozen pytest -q
- uv run --frozen python -m personal_finance.bootstrap.main --self-test

На Linux для Qt задать QT_QPA_PLATFORM=offscreen и доступный XDG_CACHE_HOME.
Windows: check-windows.cmd; инструкции docs/windows-quickstart.md.
Сценарии должны оставаться совместимыми с Windows PowerShell 5.1; сохранять BOM
и правила .gitattributes. Встроенные run-блоки shell: powershell в GitHub
Actions должны содержать только ASCII: временные файлы создаются без BOM и
PowerShell 5.1 может неверно разобрать кириллицу. Русские сообщения выносить
в отдельный .ps1 с BOM. Проверка на Linux/PowerShell 7 не доказывает работу
Windows/PowerShell 5.1. Headless CI не заменяет ручную приёмку Windows 11.
