# Изолированная проверка локального OCR

Это служебное приложение для измерения Android JNI на синтетических рисунках.
Оно не является новой версией Crown и не открывает её книгу.
В основном проекте android никаких OCR-зависимостей не добавлено.

Кандидат, лицензии, SHA-256 и ограничения описаны в
[отчёте](../../docs/android-ocr-runtime-candidate.md).
Перед сборкой подготовьте указанные там файлы в отдельном каталоге.
Бинарные файлы и модели в Git не добавляются.

Из каталога android используйте его существующий Gradle wrapper:

```powershell
.\gradlew.bat -p ../tools/android-ocr-probe -PcrownOcrCandidateDir=S:/Dev/Crown/artifacts/android-ocr-candidate-20261122 --no-daemon assembleDebug assembleDebugAndroidTest
```

После первого разрешения зависимостей проверена сборка с --offline.
Устанавливайте два полученных APK только в отдельный эмулятор:
пакеты ru.crown.finance.ocrprobe и ru.crown.finance.ocrprobe.test.
Не путайте их с проверочным APK ru.crown.finance.preview.

Запуск (замените serial только на свой выделенный эмулятор):

```powershell
adb -s emulator-5586 shell am instrument -w -r ru.crown.finance.ocrprobe.test/androidx.test.runner.AndroidJUnitRunner
```

Смотрите статусы каждого теста: 0 — успех, -3 — пропуск.
Одна строка OK не доказывает отсутствие пропусков.
Разрешение INTERNET отсутствует, модели упакованы заранее.
Четыре теста проверяют светлый и тёмный вымышленные рисунки, затем историю:
кириллицу, дату, явный знак суммы, прямоугольники слов и шесть сумм в
эталонных областях строк. Отдельно проверена отмена из прогресса hOCR
и следующая обработка после очистки. Поиск самих строк ещё не реализован.
Никакие операции в финансовую книгу не записываются.

Дополнительный срез: 18 тестов, ограниченная загрузка PNG/JPEG,
восемь ориентаций EXIF и отмена при остановке Activity. Точный результат и границы:
docs/android-ocr-lifecycle-report.md в корне репозитория.
В пробе закреплена AndroidX ExifInterface 1.4.2; рабочий APK не менялся.
Публичные материалы можно подготовить через
python -X utf8 tools/prepare_android_ocr_probe.py --output <новый-каталог>.
Первый полный CI описан в отдельном workflow android-ocr-probe.yml.

Это ещё не квалификация движка для продукта: происхождение готовых
библиотек, полный набор лицензий, отмена из интерфейса и предельные входы требуют
дополнительной проверки. Условия собственных лицензий зависимостей
сохранены в assets/licenses собранного пробника.
