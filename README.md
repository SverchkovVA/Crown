# Личные финансы

Автономное приложение для Windows 11 x64 на Python, PySide6 и SQLCipher.

Текущая работа: **этап 3 — основа приложения**. Приложение ещё не предназначено
для ведения реальных финансов. Финансовый журнал и начальные остатки относятся
к следующему, отдельно согласуемому этапу.

Инструкции запуска, результаты проверки и ограничения будут заполнены вместе
с реализацией этапа 3. Документация и интерфейс ведутся на русском языке.
