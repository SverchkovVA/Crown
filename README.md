# Crown — личные финансы

Автономное приложение для **Windows 11 x64** на Python 3.13, PySide6,
SQLAlchemy, Alembic и SQLCipher. Документация и интерфейс на русском языке.

**Ветка stage-4-ledger: версия 0.2.0.dev2, журнал с разделением по категориям.**
**Используйте только проверочные данные.** Реализованы ручные доходы, расходы,
переводы с комиссией, начальные остатки, история исправлений и остатки на дату.
Доходы и расходы можно разделить на части; подробности каждой версии видны в истории.
Полный этап 4 ещё не принят. [Первая поставка](docs/stage-4-report.md),
[разделение и проверка 0.2.0.dev2](docs/stage-4-split-report.md).

Стабильная ветка main сохраняет 0.1.2 — основу этапа 3.
Для 0.1.2 автоматические проверки Linux и Windows Server прошли,
включая сборку EXE. 26.10.2026 полный автоматический прогон 0.1.2 на Windows 11
также прошёл: после расширения регрессий 62 теста и обе нативные самопроверки. Локально выявлена и исправлена
подстановка посторонних DLL из PATH при сборке. В 0.1.2 исправлены освобождение
блокировки при закрытии из другого потока и выбор режима для кода PF1.
Ручной сценарий новой книги (повторное открытие, целостность, копия и
восстановление) подтверждён пользователем. Приёмка Windows 11 ещё не завершена;
открытие прежней книги не подтверждено.
[Проверенный прогон CI](https://github.com/SverchkovVA/Crown/actions/runs/40359183599).

## Что работает

- Создание локальной зашифрованной книги и открытие по парольной фразе.
- Освобождение блокировки при закрытии книги из потока интерфейса.
- Выбор режима полного кода PF1 покрыт синтетическими тестами; в одном ручном
  сценарии понадобился флажок восстановления, причина ещё не установлена.
- Отдельный код восстановления, показываемый после создания книги.
- Справочники банков, счетов четырёх типов, категорий и подкатегорий.
- Неизменяемые версии справочников и операций, журнал изменений, защита от повтора команды.
- Ручной журнал: начальные остатки, доходы, расходы, переводы и комиссии.
- Исправление новой версией, удаление с подробной историей, остатки на выбранную дату.
- Разделение дохода/расхода на 2–100 частей; сумма частей строго равна общей сумме.
- Схема 0002 открывается со справочниками, 0003 — с обычным журналом. Разделение
  доступно в новых книгах 0004 и после восстановления старой копии в новую папку.
- Ручное резервирование: зашифрованный потоковый файл с отдельным паролем.
- Полная проверка блоков копии, восстановление в новую папку с новым паролем.
- Проверка целостности SQLCipher, связей и полноты журнала изменений.
- Работа без сетевого соединения; сетевых функций в этой сборке нет.

## Запуск на Windows 11

Для полного автоматического прогона после установки uv распакуйте исходники
и запустите **`check-windows.cmd` двойным щелчком**. Он проверяет код, выполняет
тесты и самопроверки, собирает EXE, сохраняет `report.json` и локальные журналы.
Порядок действий: [короткая инструкция Windows](docs/windows-quickstart.md).

1. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/).
   При разработке проверена версия uv 0.12.23.
2. Откройте PowerShell в папке проекта, где находится `pyproject.toml`.
3. Установите зафиксированные зависимости:

```powershell
uv sync --frozen
```

uv создаёт `.venv` и при необходимости загружает Python версии из `.python-version`.
Для этой первоначальной подготовки нужен интернет. Готовое приложение работает
с локальными данными без него.

4. Запустите приложение:

```powershell
uv run --frozen python -m personal_finance.bootstrap.main
```

Кнопка «Создать книгу» предлагает новую папку `.pfvault` в пользовательском
каталоге приложения. Вы можете выбрать другое место. Не храните книги в Git,
папке исходников или каталоге установки программы.

## Первая проверка

Создайте тестовую книгу, сохраните код восстановления, добавьте счёт и категорию.
В разделе «Защита и копии» создайте копию, затем восстановите её в новую папку.
Убедитесь, что счета и категории сохранились. Исходная книга не заменяется.

Три разных секрета:

- парольная фраза книги открывает книгу;
- код восстановления также открывает эту книгу;
- пароль копии нужен для чтения файла `.pfbackup`.

При восстановлении задаётся новый пароль книги и показывается новый код.
Старая книга остаётся доступна по прежним данным. Перенос на другой компьютер
через резервную копию не требует DPAPI исходной Windows.

## Проверки

```powershell
uv run --frozen ruff check src tests tools
uv run --frozen ruff format --check src tests tools
uv run --frozen mypy src/personal_finance
uv run --frozen pytest -q
uv run --frozen python -m personal_finance.bootstrap.main --self-test
```

`--self-test` работает только с временными синтетическими данными. Код возврата
0 означает успех; пользовательские книги не открываются. На Linux без экрана
установите `QT_QPA_PLATFORM=offscreen` и доступный для записи `XDG_CACHE_HOME`.

## Сборка каталога приложения

На Windows:

```powershell
.\packaging\windows\build.ps1
```

Результат размещается в **новом** каталоге `artifacts/windows-build-…/app/PersonalFinance`.
Там находится `PersonalFinance.exe` и соседние файлы; переносить нужно весь каталог.
Сценарий выполняет установку по lock-файлу, сборку и самопроверку. Существующие
сборки сохраняются. При полном прогоне `check-windows.cmd` результат находится
в `artifacts/windows-check-…/bundle/app/PersonalFinance`.

Финальный NSIS-установщик и подпись относятся к этапу 9.
Linux-сборка не является Windows-программой.
