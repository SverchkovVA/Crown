# Этап 7. Сводный прогноз по счетам RUB

Кандидат 0.2.0.dev76, исходник 2bea3c2b796fcbb3377026bb124512a93c3e8bcd.
В календаре доступен выбор одного счёта или всех доступных счетов RUB.
Остаток складывается из принятых проводок. У внутреннего перевода сумма
списания и зачисления взаимно погашается; в остатке остаётся комиссия.
Расписание влияет на общий остаток один раз. Доступны детализация счетов
и проверка резерва. Сопоставление с проводкой выполняется в прогнозе одного
счёта. Все расчёты сохраняют финансовый журнал.
