# Копии и восстановление

## Процедура пользователя

1. Откройте книгу → «Защита и копии» → «Создать зашифрованную копию».
2. Выберите новое имя файла за пределами папки книги и отдельную парольную фразу.
3. Дождитесь сообщения о завершении проверки.
4. Храните хотя бы одну копию на другом физическом носителе.
5. Для восстановления выберите файл, пароль копии, новую папку и новый пароль книги.
6. Сохраните новый код восстановления и проверьте счета/категории.

Существующая папка книги и существующий файл копии не заменяются. Проверка копии
не создаёт восстановленную книгу. Повреждение/неверный пароль не публикует новую
книгу. Восстановление можно проверять, сохраняя исходную книгу.

Код восстановления помогает открыть сохранённую книгу при потере пароля. Он не
содержит финансовую историю: при утрате файлов книги нужна резервная копия.

## Формат v1

Фиксированная сигнатура PFBAK, ограниченный по размеру JSON-заголовок, Argon2id и
libsodium secretstream XChaCha20-Poly1305. Заголовок включён как дополнительные
аутентифицируемые данные каждого блока.

Первый шифрованный блок: UUID книги, ключ внутреннего SQLCipher-снимка, размер,
SHA-256, версия схемы и время UTC. Далее идут блоки снимка до 1 MiB и обязательный
пустой TAG_FINAL. Дополнительные байты, перестановка, изменение или обрыв блоков
не принимаются. Предельный размер базы этой версии — 10 GiB.

Полученный SQLCipher-снимок проверяется до упаковки. Готовый контейнер повторно
полностью читается до публикации имени. Файлы закрепляются fsync; на POSIX также
fsync каталогов. Поведение накопителя и реальные сбои питания на Windows ещё
требуют отдельного испытания.

При восстановлении все блоки проверяются в промежуточной папке. Проверяются
SQLCipher, схема, связи и история. История реплик сохраняется, но local_state
получает новую реплику, предотвращая повторное использование её последовательности.

Автоматическая ротация, расписание копий, вложения и предварительный просмотр
состава восстановления появятся позже. Пользовательские копии сейчас вообще
не удаляются приложением. Папка текущей книги не является резервной копией.
