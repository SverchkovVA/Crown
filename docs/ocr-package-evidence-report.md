# Происхождение OCR: частичные доказательства 06.11.2026

Отдельная ветка ocr-provenance-preparation. Рабочие DLL, модели, приложение,
схема0014 и криптографические форматы не менялись. Скачанные пакеты
не устанавливались; установщик Tesseract и его библиотеки не запускались.

найдено у52 из56 нативных файлов (EXE +55 DLL) в41 архивном пакете
[официального MSYS2](https://repo.msys2.org/mingw/mingw64/).
Только метаданные, нужные DLL и уведомления прочитаны из архивов;
исполнения PKGBUILD и установки пакетов не было.

## Содержимое официального установщика

Сохранённый tesseract-ocr-w64-setup-5.5.3.20260724.exe повторно сверён:
SHA-256 bee9e3434bd94fd65387d9be28cd467a41f61b1275383b55b0f59a1331270ae4
совпадает с закреплённым манифестом и метаданными
[официального релиза](https://github.com/tesseract-ocr/tesseract/releases/tag/5.5.3).
Все56 нативных членов установщика совпали с runtime-candidate.json.
Данные прочитаны в память ранее подготовленным локальным7-Zip, без
распаковки DLL в приложение и без запуска NSIS. MSI извлекателя также
сверён с закреплённым SHA-256; текущие хеши7z.exe/7z.dll записаны в доказательстве.

Это связывает весь бинарный набор с опубликованным установщиком, включая
четыре файла без совпадения с MSYS2: tesseract.exe,libtesseract-5.dll,
libgcc_s_seh-1.dll,libstdc++-6.dll. Попытка Windows Authenticode дала UnknownError при наличии сертификата:
подпись установщика не считается подтверждённой. Подпись тега не проверялась,
хранилище сертификатов не менялось. Соответствующие исходники, точный workflow и среда сборки
этим не установлены; у двух GCC DLL отдельная цепочка Ubuntu MinGW.
Версии компилятора и отметки PE служат подсказками, не доказательством исходника.

## JBIG-KIT и границы аудита

[Исходный пакет2.1-5](https://repo.msys2.org/mingw/sources/mingw-w64-jbigkit-2.1-5.src.tar.zst)
имеет проверенную подпись. SHA-256 PKGBUILD совпадает с .BUILDINFO
совпавшего бинарного пакета; SHA-256 вложенного jbigkit-2.1.tar.gz
присутствует в рецепте. Полная проверка патчей, условий и повторная сборка
не выполнены. Метаданные семейства указывают GPL-2.0; готовность
распространения всего комплекта не подтверждена.

[Машиночитаемые доказательства](ocr-package-evidence-20261106.json)
содержат байты, отдельные подписи, установщик и прежний источник JBIG-KIT.
В source_jbigkit устранён устаревший false для подписи: фактический
успешный результат уже находился в upstream_jbigkit.
byte_evidence.package_signature_verified=false по-прежнему означает,
что сам offline-инструмент не проверяет GPG. Его application_bundled=false
означает, что он ничего не подключает; в локальных проверочных сборках
Crown есть прежний ocr-runtime. Это не инвентаризация всех каталогов поставки.

Исходный инструмент/связанные компонентные проверки ранее дали25 passed;
код инструмента не менялся, повторять их из-за новых входных архивов не требовалось.
Новый реальный offline-запуск дал52/56,113 каталогов,41 подпись.
Полный лицензионный аудит, соответствующие исходники/патчи, Ubuntu GCC,
доверие и уведомления всего комплекта остаются. Флаги готовности не включены.
Исторический рецепт Tesseract обращается к keyring/master (сейчас404);
для этой проверки взят фактический main и проверен Git blob. Рецепт не менялся.

Архивы, ключи, локальные отчёты и вспомогательные сценарии находятся в
игнорируемом artifacts/ocr-package-evidence-20261106. В Git только публичные
технические хеши/ссылки и отчёт. Банковские данные в этой ветке не использовались.

## Уведомления и отдельная проверка Ubuntu

У37 из41 точно совпавшего пакета в извлечённом mingw64/share/licenses
найдено56 файлов уведомлений; их относительные имена, размеры и SHA-256
записаны. Это инвентаризация, не заключение о полноте или применимости условий.

У giflib6.1.3-1,ICU78.3-3,libidn2 2.3.8-4 и LZ4 1.10.0-1 таких отдельных
файлов в пакете не было. Это не отсутствие лицензии библиотеки.
Для них скачаны соответствующие официальные исходные пакеты MSYS2:
подписи четырёх архивов valid,PKGBUILD побайтно соответствует SHA-256
из .BUILDINFO совпавшего бинарного пакета. SHA-256 каждого вложенного
upstream-архива присутствует в рецепте. Из них прочитано13 файлов
LICENSE/COPYING и подобных уведомлений. Патчи и применение каждого условия
целиком ещё не рассмотрены; материалы не подключены к приложению.
Вместе с прежним JBIG-KIT это пять отдельно прослеженных исходных пакетов,
а не полный комплект соответствующих исходников всех41 компонентов.

Для двух GCC DLL прочитан
[официальный индекс Ubuntu](https://archive.ubuntu.com/ubuntu/pool/universe/g/gcc-mingw-w64/).
Два опубликованных amd64-пакета win32-runtime —13.2.0-6ubuntu1+26.1
и13.3.0-9ubuntu1+26.6 — дали0/2 точных совпадений каждый.
DEB/вложенные tar прочитаны без установки и исполнения scripts.
Названия и строки GCC13 не подменяют сравнение байтов; происхождение
этих двух DLL на уровне конкретного Ubuntu-пакета остаётся неизвестным.
Индекс подписи Ubuntu в этой проверке не подтверждался.
Отрицательные хеши/метаданные сохранены, чтобы не повторять выбор этих версий.

Новые данные входят в тот же машиночитаемый отчёт. Все флаги общего аудита,
полноты уведомлений, разрешения поставки и изменения runtime остаются false.
