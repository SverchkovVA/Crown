# Подготовка сценария «Обновить цены»

В dev108 подготовлен независимый сценарий для пункта A6. Его
внешний вход принимает только коды инструментов, источник и при
необходимости код режима торгов. Счёт, позиция, количество и операции
остаются в книге. Если несколько локальных позиций ссылаются на один
инструмент в одном режиме, источник получает этот код один раз.

Цены поступают нормализованными. Для акции и фонда проверяется цена
за бумагу. Для облигации требуются процент, непогашенный номинал и
НКД в валюте бумаги. Приложение сравнивает дату и, когда она предусмотрена
поставщиком, метку времени с часовым поясом. Более ранняя цена и
противоречивые данные за один момент оставляют предыдущую котировку.
Если результат по части инструментов отсутствует, найденные пригодные
цены обрабатываются отдельно.

Код сценария вызывается явно. В проверках поставщика заменяет локальная
фикстура. Обработчик в интерфейсе, конкретный сетевой поставщик и
хранилище рыночных котировок ещё не подключены. Ручные цены и текущий
портфель используют прежние входы. Решение о поставщике описано в
[сравнении источников](stage-8-price-sources.md).
