# Сохранение календарей через интерфейс

12.11.2026. Crown 0.2.0.dev71, исходник `fbf8fac`. Использована временная
синтетическая книга с явно выбранной схемой 0016. Схема новых книг и
восстановления по умолчанию 0015.

В «Отчётах → Календарь платежей…» можно сохранить расписание под именем.
Кнопка «Открыть сохранённый…» показывает список из текущей книги.
Выбранный календарь открывается отдельной формой. Предыдущий черновик
доступен через навигацию «Назад». Изменения открытого календаря сохраняются
новой версией. Совпавшее имя с другими условиями или конфликт версии показывают
сообщение об ошибке. Форма поддерживает рублёвые календари.

33 целевых GUI-теста прошли, включая создание, повторное открытие,
изменение сохранённого календаря, повторное открытие закрытой книги
и сохранение поведения черновика на 0015. Нативный сценарий выполнен
в обеих темах при 100%, 125% и 150%. Отдельный [CI](https://github.com/SverchkovVA/Crown/actions/runs/43226898716)
и полный локальный прогон запущены.
