# Инвестиционный портфель и проверка формата 0017

Dev83 добавляет сводку сохранённых позиций. Dev84, исходник 011bfd4,
подключает 0017 в отдельной квалификационной сборке. Она создаёт
новые книги 0017 и восстанавливает архивы 0002–0017 в новые папки.
При обычном открытии книга сохраняет исходную схему. Для 0016
сохраняется временный расчёт. Предыдущие сборки с поддержкой до 0016
книгу 0017 отклоняют. Формат пароля, PF1 и контейнера копии прежний.

В сводке каждая строка соответствует инструменту на одном счёте.
Верхняя таблица суммирует стоимость оставшихся партий, оценку,
реализацию, выплаты и результат раздельно по валютам. Если для
открытой позиции цены на дату нет, оценка охватывает только
оценённые бумаги, а общий результат валюты скрыт. Закрытые позиции
по-прежнему вносят реализацию и выплаты. Из строки открываются партии,
продажи, списания FIFO, выплаты и сведения о выбранной ручной цене.

## Проверка на учебной книге

1. Запустите dev84 и создайте новую учебную книгу в отдельной папке.
   Добавьте два инвестиционных счёта RUB.
2. В «Отчёты → Планирование → Расчёт инвестиционной позиции…»
   введите учебные сделки из [примера dev82](stage-8-investment-result-dev82.md).
   Сохраните позицию и повторите для второго счёта с другим кодом
   инструмента, оставив ручную цену пустой.
3. Откройте «Инвестиционный портфель…» и выберите дату сделок или позже.
   Должны быть две строки. По первой доступны итог и детализация FIFO.
   В сводке должно быть «Без цены: 1», общий итог отмечен прочерком.
4. Закройте и откройте учебную книгу. Позиции должны сохраниться.
   Создайте копию, проверьте её и восстановите в отдельную новую папку.
   Восстановленная книга должна показывать те же позиции.
   Для примера подойдёт учебная копия. Вводите секреты только в приложении.

  Сверены исходник, SHA-256, JUnit, полнота групп и отчёты. В первом
  нативном полном прогоне один тест выявил разные PNG одного учебного
  OCR-образца, два теста буфера обмена требовали offscreen. 8 повторов
  связанных OCR-тестов в нативном Qt прошли по 17 тестов. Полный
  повтор со штатной тестовой платформой offscreen прошёл 2712 тестов.

  и нативный просмотр обеих тем при 100%, 125% и 150%. Сборка прошла,
  исходники и EXE прошли по 33 шага. Точный EXE запустился в Windows
  Sandbox без сети, Python и uv. [Полный CI dev83](https://github.com/SverchkovVA/Crown/actions/runs/43392771378).
- Dev84 прошла 59 целевых проверок схем и интерфейса, в том числе 15
  исходных схем и три моделируемых отказа 0017, и ещё 6 тестов отчёта
  самопроверки и версии. Оба отчёта нативной самопроверки содержат по
  34 успешных шага. У точной сборки SHA-256 EXE
  0428e0438611adbdb290e5e8e97445b268b7494af2b1230f8272ceb5dcee5443.
  В Windows Sandbox без сети, Python и uv прошли 34 шага и запуск окна.
  [Полный CI dev84](https://github.com/SverchkovVA/Crown/actions/runs/43394018509).
  Свежие итоги полного набора и состояние веток в локальной контрольной точке.

показываются в отдельном отчёте. Источник котировок пока не выбран.
