# Масштаб изображения OCR: контрольный эксперимент

06.11.2026. Проверенный runtime не менялся. На dev56/c2d9040 проверены одни и те же
34 ранее зафиксированных синтетических макета. До первого вызова OCR сохранён
манифест исходных ожиданий и хешей всех четырёх вариантов PNG. Qt SmoothTransformation,
фиксированный размер для каждого варианта, без подбора по результату.

| Размер относительно исходника | Полностью совпали поля | Пропущено движений | Лишних движений |
|---|---:|---:|---:|
| 1:1 | 33/34 | 0 | 0 |
| 3:4 | 31/34 | 1 | 2 |
| 5:4 | 31/34 | 2 | 0 |
| 3:2 | 29/34 | 4 | 2 |

Изменение масштаба не даёт основания улучшать рабочее распознавание:
каждый испытанный альтернативный размер имеет более слабый общий результат.
Рабочий вход сохраняет исходные размеры и координаты. Эксперимент не подключён
к финансовому пути, не создаёт другого отпечатка пользовательского документа
и не меняет прежний аудит. Нельзя выбирать размер по совпадению с ожидаемыми суммами.

Это измерение только этих макетов, без оценки точности на банковских снимках.
Локальные технические файлы вне Git: основной artifacts/scale-comparison-20261106.
Манифест и отдельные отчёты сохраняются вместе с comparison.json.
