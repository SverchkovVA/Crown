# Состав Windows-поставки и сетевой адаптер ввода Qt

Ведомость dev127 содержит 107 нативных файлов PE. Все 107 совпали по SHA-256
с входами локальной сборки PyInstaller. 79 из них совпали также с хешами
`RECORD` установленных wheel. Остальные — 27 файлов среды Python и один
собранный EXE. Совпадение с установленными файлами подтверждает фактический
состав сборки. Для полного происхождения и состава уведомлений нужны данные
из исходных архивов среды, колёс и нативных зависимостей внутри них.

В поставку dev127 попал плагин `qtuiotouchplugin.dll` для сетевого сенсорного
ввода TUIO. Он единственный из 107 исследованных файлов, чей PE-импорт
ссылается на `Qt6Network.dll`. Поставляемый модуль Windows `qwindows.dll`
использует собственный платформенный ввод.

Из dev128 исключены эти два файла Windows-поставки. PySide6, Qt Core, Gui и
Widgets остаются в прежних версиях, Python-обёртка `PySide6.QtNetwork` уже
исключалась сборщиком. `libssl` и `libcrypto` входят в среду Python.
Изменение ограничено перечнем поставляемых файлов PyInstaller.
[Формат списков PyInstaller](https://pyinstaller.org/en/stable/advanced-topics.html#the-table-of-contents-toc-lists-and-the-tree-class)
