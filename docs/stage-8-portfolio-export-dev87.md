# Экспорт снимка инвестиционного портфеля

В dev87 можно сохранить локальный CSV или JSON из уже построенного
портфеля. В предпросмотре до восьми строк, в файле все позиции снимка.
Коды инструментов, количества, суммы и дата цены включаются всегда.
Названия счетов выключены по умолчанию. Проводки, идентификаторы
книги, ключи и другие секреты в файл не попадают.

JSON хранит суммы строками целых минимальных единиц, с кодом валюты
и её точностью. Неизвестные оценки и результаты обозначаются null.
CSV использует UTF-8 с BOM и разделитель «;». Неизвестные значения
остаются пустыми. Коды и названия с началом, похожим на формулу,
защищаются при открытии в табличном редакторе.

Сохранение требует отдельного выбора файла. Готовый файл доступен
для чтения без пароля. Запись внутри книги и перезапись существующего
файла запрещены. По сети файл не отправляется.

## Проверка

В новой учебной книге откройте портфель с двумя позициями, одна без
ручной цены. Нажмите «Экспорт…». В предпросмотре первоначально
четыре колонки. При включении названий счетов появляется колонка
«Счёт». Выключите её и сохраните JSON. Проверьте дату, сумму в
копейках, пустую оценку без цены и отсутствие названий. Сохраните CSV
с включённой колонкой «Счёт» в другой новый файл. При попытке
повторно выбрать первое имя Crown сообщает, что файл существует.

Прошли 50 связанных проверок, включая прежние сценарии экспорта
журнала, защиту от гонки публикации и переход через встроенную форму.
[Полный CI](https://github.com/SverchkovVA/Crown/actions/runs/43397254161).
Запуск и фактические полные результаты указаны в контрольной точке.
