# Интерфейс dev49 — 06.11.2026

Ветка ui-unslop. Стек и схема 0014 сохраняются.
Основание: [сравнение open source-проектов](open-source-reference-review.md).

## Изменения

- Системная рамка Windows 11 получает цвет текущей темы через DWM, без
  frameless-окна. Сохраняются системные закрытие/сворачивание, изменение
  размера и привязка окон. На других платформах остаётся штатная рамка.
- Стрелки размещены над левой панелью. Справа — название текущего раздела
  или открытого действия. Скрытые разделы не перекрывают текущий заголовок.
- Во встроенных формах убрана дублирующая кнопка «Закрыть»; «Назад»
  приостанавливает форму с её правками, «Вперёд» возвращает её.
  Явные «Сохранить», «Отмена» и «Вернуться к списку» с другой семантикой сохранены.
- Карточка и список названы «Карточка операции» и «История операций».
- В пакетном OCR постоянная нижняя панель: слева «Добавить операции (N)»,
  справа флажок сверки, когда подтверждения включены в настройках.
  В режиме без книги кнопка проверяет поля без финансовой записи.
- Столбцы имеют разумные исходные ширины, остаются регулируемыми и равномерно
  делят свободное место. Последний столбец не растягивается произвольно.
  Высота строк определяется после применения темы, чтобы не обрезать текст.
- Колесо над таблицей и её полями перемещает таблицу горизонтально,
  не меняя значение выпадающего списка. Shift + колесо прокручивает строки.
  Раскрытый выпадающий список сохраняет своё обычное управление.

Использован прежний подход [unslop](ui-unslop-report.md); нативная реализация,
без новых пакетов. Цвет рамки: [DWMWINDOWATTRIBUTE](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute).
Исходные OCR-свидетельства, правила денежных операций и аудит не менялись.

## Ручная проверка

1. В обеих темах проверить нативную рамку, сворачивание, максимизацию, привязку
   и уменьшение окна. Заголовок текущего раздела находится справа от стрелок.
2. Ввести поля, вернуться «Назад» и «Вперёд»: значения на месте, записи без
   сохранения нет. Закрытие книги очищает историю.
3. В пакетном OCR прокрутить тело вниз и горизонтально. Кнопка добавления и
   флажок остаются внизу, значения списков от колеса не меняются.
4. Shift + колесо прокручивает строки. Раскрытый список можно прокрутить обычно.
5. Добавить выбранные синтетические строки, проверить результат и повторную
   загрузку без дополнительных движений.

Полная ручная приёмка прежних этапов, автономность на отключённой сети,
физические 100/125/150% и чистая Windows остаются открытыми.
После контрольной точки UI пользователь разрешил продолжать OCR.
