## Реализовано

Обычный EXE автоматически подключает закреплённый модуль ocr-runtime рядом с
программой. Явный --ocr-runtime доступен для исходников/EXE; прежний preview-wrapper
сохранён. Используется тот же общий профиль и прежние Т-Банк/ВТБ, режимы psm6/11.
Приложение не ищет бинарные файлы в PATH/cwd и не скачивает их. Доверенный манифест
включён в _internal/ocr, внешний JSON не меняет хеши. До запуска проверяются
ссылки/junction, регулярность, размеры и хеши файлов; перед OCR проверка повторяется.
При отсутствии модуля меню OCR нет; ошибка подключения показывает понятное
предупреждение и сохраняет обычную работу с книгами.

Стандартный архив CI содержит только код и манифест. Tesseract EXE/DLL/модели
не публикуются с ним, отдельный закреплённый кандидат проверяется локально.
Полный аудит лицензий всех DLL ещё не завершён; публичный дистрибутив не объявлен.
Флаги готовности в runtime-candidate.json остаются false без новых доказательств.
