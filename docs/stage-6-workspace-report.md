# Формы книги, вклады и масштаб в dev39–dev40

04.11.2026. Продолжение пункта 4 после
[встроенного OCR](stage-6-inline-ocr-report.md) и
[действий в разделах](stage-6-inline-actions-report.md).

В dev39 создание, открытие и восстановление книги встроены в главное окно.
После создания или восстановления стартовый экран показывает PF1. Чтобы
перейти в книгу, пользователь отмечает сохранение кода и нажимает «Готово».
Из недавних книг сразу открывается форма доступа. Системные диалоги выбора
файла или папки открываются по действию пользователя.

Сохранённые сценарии вкладов, история версий, изменение условий, повторный
расчёт и сохранение работают в разделе «Отчёты». При закрытии книги
активные формы очищаются. Смена парольной фразы и механизм восстановления
PF1 относятся к отложенному пункту 5.

В dev40 первый размер окна учитывает доступную рабочую область. На Windows
проверено окно при системном коэффициенте Qt 3. До исправления высота
окна составляла 760 логических пикселей при 672 доступных. После
исправления окно помещается, последняя строка «Настройки» видна.
Высота изменена только у пунктов боковой навигации.

## Что осталось принять вручную

1. На новой тестовой книге открыть OCR из журнала. Проверить выбор файла,
   перетаскивание и вставку, затем вернуться из проверки в журнал.
2. В журнале добавить и исправить проверочную операцию. Открыть её из
   отчёта и вернуться в отчёт. В сохранённых вкладах пересчитать и сохранить
   тестовый сценарий.
3. В настройках создать и проверить копию. Восстановить её в новую папку,
   подтвердить сохранение нового PF1 и повторно открыть книгу из недавних.
4. На Windows 11 проверить работу без интернета и при системных 100%, 125%
   и 150%. На чистой Windows без Python и uv проверить запуск полного
   каталога приложения. Нативные автоматические проверки масштаба проводились
   с настройками процесса Qt.
