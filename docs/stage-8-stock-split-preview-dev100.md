# Черновой расчёт дробления акций

В «Отчёты → Планирование → Расчёт инвестиционной позиции…» добавьте
покупку акции. Через «Добавить событие» выберите «Дробление акций».
Укажите дату, порядок внутри дня и целый множитель. Например, 3 акции
после дробления ×100 превращаются в 300, а себестоимость партии сохраняется.

В отчёте видно применённое дробление. Цены до его даты больше не
применяются: укажите цену новой единицы на дату дробления или позднее.
При расчёте на более раннюю дату остаются прежнее количество и цена.
Сохранение позиции с таким событием в 0017 недоступно. Удаление его из
черновика снова позволяет сохранить обычную позицию. Расчёт не меняет
операции денежного журнала.

Новая запись испытывается отдельно; подробности в
[проекте формата 0018](stage-8-stock-split-preparation.md).
