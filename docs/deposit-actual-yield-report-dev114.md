# Фактическая доходность отдельного счёта вклада — dev114

В «Отчёты → Сохранённые сценарии вкладов → План и факт» можно включить расчёт
годовой доходности. Для этого выберите счёт, где записаны все движения только
одного вклада, и категорию зачисленных процентов. Настройка действует на этот
расчёт. Для счёта с другими средствами используйте сравнение сумм процентов.

Внесение на вклад учитывается в день операции. Снятие учитывается в день
получения денег. Проценты, зачисленные на этот счёт, входят в его остаток или
переведённую со счёта выплату. Комиссия перевода уменьшает результат один раз.
Вкладка «Движения вклада» открывает исходную версию каждой записи. При
отрицательном остатке, смешанной категории или ряде движений с неоднозначной
годовой доходностью результат для этой ставки недоступен с пояснением.
План и факт суммы процентов остаются видны.

Временной расчёт использует календарные дни и 365 дней в году. Ставка
относится к записанным потокам и остатку на указанную дату. Отдельный банковский
счёт выплаты процентов и связь между несколькими договорами пока не предусмотрены.
Схема и сохранённые записи книги при расчёте не меняются.

Локально прошли 24 связанные проверки, включая штатный путь GUI из списка
вкладов и исходную неизменяемую версию. В двух темах и трёх масштабах проверены
кнопки, таблица и доходность. Сборка Windows и самопроверка исходников с OCR
прошли. Полная квалификация отслеживается в контрольной точке.
