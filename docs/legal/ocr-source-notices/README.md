# Предварительные исходные уведомления OCR

Сохранены без правок тексты из первичных репозиториев:

- Tesseract 5.5.3: LICENSE и AUTHORS;
- модели tessdata_fast: LICENSE с commit 87416418657359cb625c412a48b6e1d6d41c29bd.

manifest.json указывает источник, ref, Git blob SHA, размер и SHA-256 каждого текста.
Это файлы исходных уведомлений двух компонентов, без ведомости всех 55 DLL.
Их наличие не завершает лицензионный аудит OCR-модуля.

Готовый runtime и правила его сборки не изменены. Этот предварительный каталог
не подключён к PyInstaller. Прежде чем включать OCR в обычную поставку, нужны
полное соответствие бинарных компонентов исходникам/пакетам, уведомления
и выполнение применимых условий всех зависимостей.
