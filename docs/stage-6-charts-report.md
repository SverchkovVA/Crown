## Что доступно

В «Отчёты → Доходы и расходы → Графики» есть месяцы и расходы по категориям.
Валюта выбирается отдельно; по 6 месяцев/8 категорий на странице, масштаб
страниц одного вида/валюты одинаков. Пустые месяцы не выдумываются. Отрицательный
расход — возврат, он выделен также штриховкой. Начальный остаток/свой перевод
не дают доход/расход, комиссия входит в расход. Нулевой итог категории сохраняется.
Нажатие столбца открывает операции месяца либо вклад выбранной категории из того
же снимка. Точные суммы/полные названия/переходы с клавиатуры доступны в таблицах.

Суммы/подписи остаются целыми минимальными единицами. Выявленный OverflowError
NumPy для агрегата свыше int64 исправлен ограниченными целыми координатами
картинки: они не возвращаются в финансовые расчёты. Одна копейка рядом с большой
суммой сохраняется точно в подписи и снимке. Сокращается только слишком длинная
подпись категории; полное название остаётся в таблице. Canvas отключает обработчик
и освобождает рисунок при закрытии. Новых данных/SQL/автоматического экспорта нет.

При небольшом окне область графика прокручивается; высота короткого графика
подстраивается, лишние кнопки/повторная инструкция источников скрыты на этой вкладке.
Семь основных разделов остаются прежними. Это не завершение полной аналитики:
сравнения, фильтры при построении, балансы/денежные потоки, вклады/проценты впереди.

## Зависимости и сборка

Подключён согласованный Matplotlib 3.11.2; прежние закреплённые версии не изменены.
Полный состав в uv.lock. PySide6 выбирается до QtAgg, pyplot и toolbar не подключены.
В spec явно указан только QtAgg. Вложены 37 неизменённых лицензионных файлов
12 пакетов, их SHA-256 сверены с docs/legal/python-packages/manifest.json.
Две ошибочно скопированные служебные .py packaging исключены из legal.
Байты лицензий сохраняются через локальный .gitattributes; полная лицензионная
приёмка финальной поставки остаётся отдельной задачей. В source_sha256 теперь
входят THIRD_PARTY_NOTICES.md и docs/legal, частные artifacts/обычная документация
по-прежнему исключены. Это новый отпечаток версии, не пересчёт доказательств dev15.

## Ограничения и решение пользователя

Универсальный OCR остаётся предпросмотром без записи, схема 0012 не активна.
[Подготовленный проект](generic-ocr-storage-proposal.md) ждёт конкретного согласования
после отказа автоматической проверки разрешений. Старые книги не мигрируются
при открытии, восстановление только в новую папку. Пользовательские книги не читались.
Ручная приёмка этапов 3–5, автономность сети и чистая Windows без Python впереди.

Пятичасовой лимит обновился; одноразовое продолжение от 06:03 МСК сработало.
Отработавшая автоматизация crown удалена, повторных запусков она не создаёт.
Предыдущий отложенный коммит отчёта dev15 был остановлен из-за лимита проверки
разрешений; после сброса он сохранён без обхода проверки. Другой отказ на создание
нового теста безопасно разрешён проверкой отсутствия и атомарным режимом x.

## Уточнения документации

  заменено фактом опубликованного репозитория/проверочных сборок, без заявления
