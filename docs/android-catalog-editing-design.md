# Android: редактирование справочников

23.11.2026. Продолжение разрешённого полного Android-приложения.
Стек Kotlin/Compose/Room/SQLCipher сохраняется.

## Решение реализации

Используем отдельный неизменяемый журнал версий поверх исходных таблиц.
Перезапись исходных строк потеряла бы прежние названия; отдельные новые таблицы
для каждого вида повторяли бы один контракт. Общий журнал содержит вид,
идентификатор, поля, архив, предшественника и признак создания.

Прежние записи мигрируют как исходная версия 0 без выдуманной даты создания.
Для новых банков, счетов и категорий исходная строка и событие создания
пишутся одной транзакцией. При восстановлении события воспроизводятся по порядку:
новый элемент появляется в момент своего события. Это допускает повторное
использование имени после переименования/архивирования и сохраняет ссылки.

Банк: название, архив. Счёт: название, банк, вид, архив. Категория: название,
родитель того же вида, архив. Вид существующей категории неизменяем — это
решение реализации для сохранения смысла записанных расходов/доходов.
Родитель не может образовать цикл. Новый/изменённый родитель и новый банк
должны быть действующими; неизменённая архивная ссылка может сохраняться.
Архивирование родителя не удаляет его дочерние элементы.

Активные имена уникальны: банк/счёт отдельно, категория внутри вида.
Архив обратим, удалений нет. Ожидается точная версия, включая номер,
чтобы отказать и при возврате имени A → B → A после открытия старой формы.
Неизменённая команда отклоняется, финансовые проводки не создаются.

## Финансовые ссылки и интерфейс

Архивные элементы остаются в остатках, истории, фильтрах и отчётах.
Новые операции не получают архивный счёт/категорию. Исправление сохраняет
прежнюю архивную ссылку, но не назначает другую архивную. Возврат может
сохранить счёт/категорию исходной покупки. Отмена операции не требует
возвращать справочники из архива. Правила не предлагают архивные категории.

Редактирование и история открываются из существующих разделов справочников
и кнопки «Управление счетами» в разделе «Счета». Форма сохраняет изменения
закреплённой кнопкой.
Исходные денежные остатки не изменяются через справочник.

## Совместимость и проверки

Room 14 добавляет журнал, копия v13 сохраняет его и читает v1–v12.
Это политика обновления Android; форматы и правила Windows не меняются.
Проверить заполненные схемы 1–13, восстановление всей истории, ссылки,
цикл, уникальность, архив, повторное имя, устаревшую форму и ABA,
закрытый месяц и неизменность журнала/остатков, активные выборы,
возврат из архива, UI в обычной/компактной темах и настоящий путь MainActivity.
