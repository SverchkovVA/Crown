# Лицензионные тексты основы Windows-поставки

В `docs/legal/windows-foundation` добавлены 13 исходных файлов 11 компонентов.
Двенадцать файлов сверены с `RECORD` установленных колёс из закреплённого
окружения. Текст CPython скопирован из установленной среды Python 3.13.16.
Ведомость фиксирует компонент, версию, относительный исходный путь и SHA-256.
Байты текстов сохраняются при извлечении Git на Windows и Linux.

PyInstaller помещает эту папку и ведомость в `_internal/legal`. Измерение
dev128 подтверждает наличие соответствующих модулей. Текст MarkupSafe уже
включался самим PyInstaller. Комплект математических библиотек по-прежнему
содержится в `docs/legal/python-packages`.
[Происхождение нативных файлов](stage-9-windows-native-origins.md)

Отдельного подтверждения еще требуют входные архивы управляемого CPython и
его нативные зависимости, включая OpenSSL и Microsoft Runtime, точные
компоненты Qt и их транзитивные лицензии, а также модуль OCR. Для Qt нужно
сверить применимые условия, уведомления, исходный код и возможность замены
соответствующих библиотек. Опубликованный дистрибутив требует отдельной
приёмки этого комплекта.
[Лицензии Qt для Python](https://doc.qt.io/qtforpython-6/licenses.html),
[метаданные и лицензии Python Build Standalone](https://github.com/astral-sh/python-build-standalone/blob/main/docs/distributions.rst)
