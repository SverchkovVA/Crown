## Поведение

«Любой банк» автоматически выбирает карточку/список и передаёт его в прежний
Ledger/OcrImporting только для схемы 0012. Карточка имеет финансовую подготовку;
выбранные строки списка записываются одной транзакцией. Свои переводы/исключения,
дата/валюта по настройке, отключаемые флажки и итоговое окно остаются общими.
Аудит сохраняет исходные поля и исправления. Известная другая валюта не становится RUB.

Без книги и в старых схемах остаётся предпросмотр в памяти. Есть пояснение:
создать новую книгу либо восстановить проверенную копию только в новую папку.
Исходные книги при открытии не обновляются. Новых изменений схемы/криптоформата нет.

## Приёмка и ограничения

Необязательный сценарий: artifacts/manual-ocr-dev18/start.cmd и ПРОВЕРКА.txt,
искусственные PNG. Пользователь создаёт новый тестовый пароль сам. Обычный EXE
по-прежнему без OCR-runtime/меню; отдельный запуск использует закреплённый
локальный runtime. Универсальный профиль не обещает поддержку любого банка/макета.
Нет измеренной точности на размеченном наборе; Яндекс Пэй/поставка runtime,
чистая Windows/автономность и ручная приёмка этапов 3–6 не закрыты.
