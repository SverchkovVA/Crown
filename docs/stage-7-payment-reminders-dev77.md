# Этап 7. Напоминания о платежах

Версия 0.2.0.dev77, исходник 0e4cd7e0cc1f24aa5724e5b9c9e9dd4beffd9d1f.
В «Отчёты → Планирование → Календарь платежей… → Открыть сохранённый…»
выберите календарь и включите «Напоминать об ожидаемых расходах».
Если в расписании есть расходы на ближайшие семь дней, в «Операциях»
появится кнопка «Платежи по календарю» с количеством. По кнопке открываются
даты, названия и суммы. Первый день периода — сегодня, последний — через
шесть дней. Фактические оплаты сверяются отдельно в прогнозе счёта.

Выбран один календарь на реплику книги. При включении другого календаря
прежний выбор заменяется. На этом ПК сохранены ключ из хеша идентификатора
реплики и идентификатор календаря. Названия, даты, суммы и расписания
читаются из открытой зашифрованной книги. Восстановленная реплика начинает
с выключенными напоминаниями. Книга, схема 0016 и журнал сохраняются при
просмотре и смене локальной настройки.
