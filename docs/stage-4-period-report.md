# Закрытые периоды — 0.2.0.dev4

Локальная часть A4 в разрешённом этапе 4, ветка stage-4-ledger. Main сохраняет
0.1.2. [Предыдущая поставка возвратов](stage-4-refund-report.md). Версия только
для синтетической проверки; полный этап 4 и приёмка Windows 11 не завершены.

## Реализовано

Раздел «Периоды» закрывает календарный месяц всей книги. Добавление, исправление
и удаление операций в нём запрещены, в том числе перенос даты из закрытого
месяца. История и копии доступны. Повторное открытие требует причину; закрытие,
открытие и повторное закрытие хранятся отдельными неизменяемыми версиями.

Проверяются новый и старый месяц внутри финансовой транзакции. SQL-триггер
дублирует запрет при запечатывании версии. Состояния периодов и операции
сериализованы общим RLock; повтор команды не пишет новых данных. Возврат закрытой
покупки в более позднем открытом месяце разрешён. Решение: [ADR-0005](adr/0005-closed-periods.md).

## Совместимость

Новая схема 0006, чтение 0002/0003/0004/0005/0006. Старые книги при открытии
не обновляются. Новые функции получают только новая книга или промежуточная
восстановленная копия в новой папке с новыми паролем/PF1/репликой.
Исходник и контейнер не заменяются. Старой программой 0006 не открывайте.
Миграции 0001–0005, форматы ключей и копий v1, финансовые payload/хеши и стек
сохранены. В uv.lock изменилась только версия локального пакета.
