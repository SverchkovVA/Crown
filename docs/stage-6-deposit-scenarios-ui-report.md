## Поведение

В «Отчёты» добавляется «Сохранённые сценарии вкладов…». Команда доступна
только при открытой книге со схемой 0013 и вне фоновой задачи. Схема прежняя:
новых таблиц/миграций, фактических процентов и финансовых проводок не добавляется.

Список поддерживает поиск по названию, архивные записи и явный выбор строки.
Без выбора доступно только создание. Для выбранного сценария доступны расчёт,
изменение условий, копирование, переименование, архив/возврат и история версий.
Условия загружаются в существующую форму без потери ставок/движений/ограничений.
Результат сначала пересчитывается, затем сохраняется явной кнопкой и названием.
Закрытие/отмена не создаёт версию. Старые версии не редактируются:
их можно рассчитать или использовать для новой копии.

Контроллер выполняет обращения к книге/расчёты рабочей задачей с mutex сессии.
Перед показом результата проверяется, что активна та же книга. Изменение
использует ожидаемую версию и идентификатор команды; ошибка сохраняет условия
для исправления/повтора. Чтение, расчёт и сохранение сценария не меняют журнал
и остатки. Это сохранённые предположения прогноза, а не банковский вклад.
