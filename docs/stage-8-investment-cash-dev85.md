# Сверка инвестиционных событий с денежным журналом

Dev85 показывает кандидатов из принятого журнала. В расчёте участвуют
записи «Доход» и «Расход» с теми же счётом, датой, валютой и точным
знаковым движением. Для покупки сумма включает комиссию и НКД.
Для продажи и погашения берётся фактически полученная сумма за вычетом
комиссии. Купон и дивиденды сопоставляются по зачисленной сумме.
Начальные остатки, переводы и возвраты в эту сверку не входят.

Если одному движению соответствуют несколько инвестиционных событий
или у одного события несколько кандидатов, строка отмечается
«Нужно уточнить». Строка с одним кандидатом даёт переход к версии
операции на момент формирования отчёта. Совпадение суммы не
подтверждает связь. Сверка не создаёт проводки и не меняет категории.
Уже внесённые операции по-прежнему учитываются по выбранным категориям.

## Ручная проверка

1. Создайте учебную книгу и инвестиционный счёт RUB.
2. Сохраните покупку 3 бумаг на 10,00 ₽ с комиссией 0,01 ₽.
3. В «Операциях» добавьте учебный расход 10,01 ₽ на тот же счёт
   и дату. Откройте «Отчёты → Планирование → Инвестиционный портфель…»,
   выберите дату сделки и нажмите «Сверить с журналом».
4. Выберите покупку. Должен отображаться «Один кандидат». Кнопка
   «Показать операции журнала» открывает расход. «Операция из снимка»
   показывает сохранённую версию.
5. Создайте второй учебный расход с теми же реквизитами. Постройте
   отчёт заново. Оба движения будут доступны, статус — «Нужно уточнить».
   Остатки и журнал при просмотре сверки не меняются.
