# Смена парольной фразы из настроек в dev121

В открытой книге выберите «Настройки → Защита и копии → Сменить парольную фразу…».
Введите действующую парольную фразу, затем новую дважды. После сообщения
«Парольная фраза заменена» при следующем открытии вводите новую. Пробелы в
начале и конце фразы считаются её частью.

Форма открывается внутри страницы. При ошибке доступа она остаётся открытой
для повторного ввода. Поля маскируют текст и очищаются перед запуском записи
и при скрытии формы. Парольная фраза используется только для смены обёртки
ключа книги. Правила записи описаны [в отчёте dev120](password-publication-dev120.md).

Прежний код PF1 продолжает открывать ту же книгу. Пароль уже созданной
резервной копии остаётся отдельным. Для смены фразы требуется знать её
текущее значение. Повторного показа или выпуска нового PF1 здесь нет.

## Ручная проверка

Создайте новую учебную книгу. Сохраните выданный PF1 отдельно. В книге
добавьте учебный счёт, затем откройте форму смены фразы. Введите разные новые
фразы и проверьте сообщение о несовпадении. Затем повторите новую фразу и
сохраните. Закройте книгу, проверьте отказ со старой фразой и вход с новой.
После закрытия снова откройте книгу прежним PF1 и найдите тот же счёт.


Смена фразы относится к текущему ключевому файлу. Отдельно сохранённая копия
прежнего ключевого файла всё ещё содержит обёртку под прежнюю фразу. При
смене фразы новый ключ базы не выпускается.

В самопроверке появился шаг `change_book_password`. Он меняет фразу
временной книги, проверяет отказ со старой фразой и повторное открытие по
новой и исходному PF1, затем сверяет остатки. Стандартная самопроверка содержит
33 шага, с локальным OCR — 35.

## Проверки

По 35 нативных шагов пройдены в исходниках, собранном EXE и Windows Sandbox
без сети, Python и uv. SHA-256 EXE
`6a9464a3793b202dbdd79c4c8481a056d02148d4bc5d69af4e5f3056896e19be`.
На 17 временных книгах схем 0002–0018 проверены исходный PF1, отказ со старой
фразой и открытие новой фразой в dev121 и предыдущей dev117. Байты всех
баз совпали до и после смены. Форма отрисована при 100%, 125% и 150% в
обеих темах. Итоговый связанный набор: 11 тестов Windows Qt.

Предварительный запуск — `artifacts/start-preview-password-settings-dev121.cmd`.
Полный локальный прогон и [CI](https://github.com/SverchkovVA/Crown/actions/runs/43846728258)
продолжаются.
