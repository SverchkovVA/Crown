# Матрица требований

Весь конечный функционал остаётся обязательным. Основа этапа 3 не является MVP
финансового учёта и не объявляется законченным продуктом.

| Требование | Реализовано | Проверено тестами | Ограничения | Статус |
|---|---|---|---|---|
| 5.1 Счета и операции | Банки, счета, категории, точные типы | Справочники и точные суммы | Нет операций и остатков | Частично |
| 5.2 OCR | Нет | Нет | Оба типа и три банка в плане | Запланировано |
| 5.3 Вклады | Нет | Нет | Условия и проценты не реализованы | Запланировано |
| 5.4 Категории | Создание и подкатегории | Типы и родительские связи | Нет классификации и split | Частично |
| 5.5 Аналитика | Нет | Нет | Нет финансовых отчётов | Запланировано |
| 5.6 Бюджеты и цели | Нет | Нет | — | Запланировано |
| 5.7 Регулярные платежи | Нет | Нет | — | Запланировано |
| 5.8 Прогноз | Нет | Нет | — | Запланировано |
| 5.9 Инвестиции | Только тип счёта | Нет расчётов бумаг | Акции/облигации/БПИФ, котировки кнопкой | Запланировано |
| 5.10 Финансовое состояние | Нет | Нет | — | Запланировано |
| 5.11 Копии | Ручная копия, проверка, восстановление | Повреждение, обрыв, пароль, новая реплика | Нет расписания и вложений; Windows не проверена | Частично |
| 5.12 Синхронизация | UUID и основа истории | Локальная атомарность | Нет сети, QR и конфликтов | Подготовка |
| 5.13 Экспорт | Нет | Нет | Экспорт не заменяется резервной копией | Запланировано |
| A1 Сверка | Нет | Нет | Не подгонять остатки автоматически | Запланировано |
| A2 CSV/OFX | Нет | Нет | Общий путь с OCR | Запланировано |
| A3 Возвраты | Нет | Нет | Дата возврата, связь с покупкой | Запланировано |
| A4 Закрытие периодов | Нет | Нет | Явное открытие для финансовой правки | Запланировано |
| A5 Теги и фильтры | Нет | Нет | Сохраняются и синхронизируются | Запланировано |
| A6 Котировки | Нет | Нет | Только явное действие, локальный кэш | Запланировано |
