# Источники цен для Crown

Проверены официальные страницы 15.11.2026. Штатный способ сейчас —
ручная цена с датой, валютой и единицей расчёта. Сетевой источник
ещё не утверждён. Выбор источника не требует менять стек или
переносить расчёт портфеля из локального приложения.

| Вариант | Что даёт | Условия |
|---|---|---|
| ИСС Московской биржи | Биржевые инструменты, режимы торгов и данные с задержкой. Доступность последних цен и истории зависит от набора данных. | Русская страница ИСС ограничивает использование ознакомлением. Для автоматической загрузки в Crown, хранения и передачи цен вместе с экспортом или синхронизацией нужно уточнить условия у биржи. [ИСС](https://www.moex.com/a2193), [порядок использования данных](https://www.moex.com/ru/datapolicy). |
| T-Invest API | Цены последних сделок и справочник инструментов. Для облигаций цена задаётся процентом от номинала, датированные НКД и номинал требуют проверки. | API доступно клиентам Т-Банка. Нужен персональный токен для чтения. Документация исключает ретрансляцию данных. [Типы токенов](https://developer.tbank.ru/invest/intro/intro/token), [условия в FAQ](https://developer.tbank.ru/invest/intro/faq), [единицы цены](https://developer.tbank.ru/invest/intro/useful-info/points). |
| Ручная цена | Все три согласованных вида бумаг. Источники и даты выбирает пользователь, расчёт офлайн. | Требуется ввод. Журнал ручных цен уже поддерживает исправление по дате и историю сохранённых версий. [Ручные цены](stage-8-investment-prices-dev91.md). |

Перед подключением нужен выбранный источник и понятные условия хранения,
отображения и передачи результата. При нажатии «Обновить цены» достаточно
идентификаторов инструментов. Коды пользователя, книга, имена счетов,
сделки, количества и остатки в запрос не входят. В сохранённой цене
нужны источник, дата сделки или торговой сессии, единица и валюта.
Для облигаций нужны непогашенный номинал и НКД на дату цены. При неоднозначной
площадке или отсутствующих данных прежняя цена сохраняется с датой,
а по инструменту показывается причина пропуска.
