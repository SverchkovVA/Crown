Этот повтор — регрессионный: ошибка уже использовалась для изменения кода.
Банковская точность и независимый общий успех этим не подтверждены.

Правило узкое: одна сумма с единственной подписью «Траты», «Доходы» или
«Расходы» в той же визуальной строке исключается из кандидатов операций.
Прежние сводные признаки сохраняются. Дополнительные слова, например
«Доходы от аренды», не отбрасываются только по началу описания.
Основная сумма карточки не подменяется сводной; исходный OcrDocument
и координаты не меняются. Контексты generic-card-v9 / generic-history-v7.

Книга по прежнему контракту хранит слова выбранных полей и SHA-256 полного
документа. Все слова изображения не добавляются в каждую строку аудита.
Старые записи v1/v8 неизменны, новый контекст не записывает повторное движение.
Сводка без операций не запускает финансовую запись даже без флажков сверки.
