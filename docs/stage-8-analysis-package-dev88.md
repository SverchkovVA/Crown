# Локальный пакет для ChatGPT

В «Отчёты → Аналитика → Пакет для ChatGPT…» выбираются границы периода
включительно. По умолчанию файл содержит суммы проведённых доходов и
расходов и чистый поток по месяцам и валютам. Переводы между своими счетами
и начальные остатки не входят в доходы и расходы. Возвраты корректируют
направление исходного движения по правилам отчёта. В расчёте используется
дата проведения, переводы валют не выполняются.

Можно включить категории с псевдонимами «Категория 1», «Категория 2» и
оценку портфеля на конец периода. Оба пункта выключены по умолчанию.
Пакет не содержит имён счетов и инструментов, назначений платежей, заметок,
идентификаторов книги, отдельных операций или секретов. Псевдонимы категорий
действуют внутри одного файла. При отсутствии цен оценка портфеля частичная.
Суммы хранятся точными десятичными строками с кодами валют.

Предпросмотр и файл используют один снимок. Предпросмотр показывает до 200
месяцев или категорий, файл включает весь выбранный состав. Пользователь
выбирает новое имя вне папки книги. JSON сохраняется открытым локальным
файлом. Crown никуда его не отправляет.

## Проверка

В новой учебной книге с операциями за два месяца проверьте суммы
в «Доходы и расходы» и месяцы в пакете. Включите категории и портфель
и сравните вкладки предпросмотра с новым JSON. Сохраните второй вариант
с отключёнными настройками. Проверьте отсутствие названий, отдельных
операций и дополнительных наборов в файле по умолчанию.
