# Этап 5: исправления ручной проверки — 0.2.0.dev11

28.10.2026, stage-5-ocr. База: [принятый автоматикой dev10](stage-5-confirmation-report.md).
Пользователь уточнил двенадцать пунктов, удаление отдельной галочки и возможность
отключить подтверждения. Параллельная работа остановлена по последующему запросу;
дальнейшая интеграция и проверки выполняются одним агентом.

## Реализованные изменения

| Пункт пользователя | Результат |
|---|---|
| 1. Начальные банки | Новые книги создаются без банков; пользователь создаёт их сам. Ранее созданные книги/счета сохранены |
| 2. Порядок вкладок | Операции; Счета; Теги и фильтры; Категории; Периоды; Правила категорий; Защита и копии. Лишний Обзор убран |
| 3. Понятность/контраст | Явные цвета текста/полей/выбора/disabled, видимый фокус, SVG флажков/радиокнопок/стрелок, пустые состояния и текст ошибок |
| 4. Шесть строк вместо четырёх | Приняты 1–2 цифры копеек и подписанные суммы без валюты; нужная история теперь даёт шесть предложений |
| 5, 11. Валюта | Настройка неизвестной валюты автоматически заполняет RUB — единственную поддержанную валюту текущего финансового UI |
| 6. Отдельная операция ВТБ | Поддержаны денежный хвост справа, равные Р/P и дата рядом с подписью; для отсутствующих полей один ограниченный PSM 11. Обе локальные карточки дают полные предложения |
| 7. Шаблоны | Маски даты/времени вставляют точки/двоеточие, сохраняют возможность пустого времени |
| 8, 12. Свои переводы | Имена предлагают TRANSFER между двумя своими счетами без дохода либо полное исключение. Связи имён хранятся зашифрованно |
| 9. Не сохранялись правки | Уточнено: проверка полей OCR. Галочка одной операции убрана, причины неполноты видны, отмена/ошибка списка сохраняет правки |
| 10. Год/весь список | День/месяц получают текущий/заданный год; строки редактируются в одной таблице и записываются атомарно одной кнопкой |
| Последующие уточнения | Четыре флажка и итоговое окно отдельно отключаются; точные повторы при выключенном окне показываются прямо в списке |

[Точный контракт](ocr-workflow-contract.md), [ADR-0013](adr/0013-ocr-workflow.md).
Новая схема 0011. Состав зависимостей, ключи, шифрование, контейнер копии и
прежние финансовые хеши не менялись. Версия проекта в uv.lock обновлена.
Обычный EXE по-прежнему без OCR-runtime/меню; опытный launcher содержит оба банка.

## Полученные доказательства

- 98 целевых регрессий прежнего OCR: passed за 72,87 с.
- Настройки/атомарный пакет/копия: 17 passed за 13,91 с; миграция 0010→0011
  и отказ DDL: 2 passed за 6,30 с. Предыдущие определения SQL-защит сохраняются.
- Финальные целевые проверки: 79 passed за 92,65 с; после последнего уточнения
  отключённых диалогов 8 GUI-тестов passed за 13,01 с. Проверены маски реальным
  вводом цифр, запись без подтверждений, перевод вместо дохода, исключение,
  отмена/ошибка без потери правок и повторы без нового итогового диалога.
- Защита второго прохода и режим запуска: отдельный синтетический набор прошёл;
  непроведённый/неоднозначный результат не заменяется, известные поля не теряются.
- Ruff/форматирование всего кода: 180 файлов; Mypy Windows/Linux: 105 исходных.
  Полный прогон/сборка и окончательный CI выполняются, результаты будут добавлены ниже.
- Самопроверка расширена до 20 шагов: persist_ocr_workflow проверяет версии
  настроек, пакетную квитанцию/повтор и SVG-ресурсы. Восстановление проверяет их перенос.

Первый полный запуск намеренно остановлен после обнаружения зависимости DPI от
QGuiApplication. Это не успешный прогон и не скрытая ошибка тестов:
artifacts/windows-check-20261028-200621-2736f48918e34aa5aeb395f1073bd183/report.json.
Окончательный прогон запущен отдельно после исправления DPI и второго прохода.

## Локальные примеры и отдельная синтетика

Десять файлов из разрешённой локальной папки проверены без передачи текста,
сумм, имён файлов или изображений в Git/CI/чат. Все исходные SHA-256 до/после
совпали, финансовые книги не записывались. Т-Банк: истории дают 5/6/5 предложений,
для всех 16 есть предложение даты с годом. ВТБ: история даёт четыре предложения;
две отдельные карточки имеют полные предложения обязательных полей после
подстановок и ограниченного дополнительного прохода. Это не ручная разметка
точности и не доказательство корректности каждой финансовой операции.
Четыре отдельные карточки Т-Банка остаются частично поддержанными: сумма в трёх,
полный набор без ручной правки не получен. Это ограничение не скрывается.
Агрегаты: artifacts/ocr-dev11-private-aggregate.json.

На собственной вымышленной истории настоящий закреплённый Tesseract дал шесть
строк; GUI без подтверждений записал шесть операций, ожидаемый остаток +1001,50 RUB.
Повтор команды и повтор после зашифрованной копии/новой папки восстановления
сохранили ровно шесть операций. Исходный PNG не изменился. Нативные скрытые Qt-окна,
без управления рабочим столом. Ранний отчёт до последних уточнений:
artifacts/ocr-dev11-native-b598dadbcfbe429d93dbda49eec084e5/report.json.
Итоговая визуальная проверка текущего кода выполняется отдельно.

Измеренные пары контраста основного текста/подсказок/кнопок/ошибок/disabled дают
5,10–13,64:1; цветовой статус сопровождается текстом. Использован ориентир
[W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)
и [видимый фокус](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/).
Это проверка конкретных цветов и форм, а не заявление полной сертификации WCAG
настольного приложения. Системный DPI, скринридер и чистая Windows требуют отдельной приёмки.

## Что остаётся

Новая тестовая книга либо копия/восстановление в новую папку нужны для списка
и собственных отправителей; открытие 0010 само не мигрирует оригинал.
Проверить следует порядок разделов, настройки без галочек/итогового окна,
свой перевод, одну запись всего списка и повтор. Подготовка новых реальных
примеров не обязательна; секреты и значения в чат не нужны.

RUB только; сохранённые черновики и GUI-просмотр аудита не добавлены.
Яндекс Пэй, визуальные перекрытия разных изображений, банковская разметка точности,
лицензии/поставка runtime, чистая Windows и полная ручная приёмка остаются впереди.
Этап 5 не объявляется завершённым; этапы 6+ не начаты.

## Исправленные расхождения документации и кода

- Начальные банки, порядок/Обзор, обязательная галочка одной операции и четыре
  постоянных флажка больше не описывают текущий UI; изменены по прямым указаниям.

  проход движка и зависимая от Qt нормализация заменены текущим контрактом.
- «Одна строка за проход с потерей остальных правок» относится к dev10/0010;
  dev11/0011 имеет список и атомарный пакет. Исторический отчёт помечен версией.
- Head 0010/старые диапазоны, отсутствие настроек/пакетных квитанций, 19 шагов и
  бюджеты 25/35 минут актуализированы на 0011, 20 шагов и 30/40 минут.
