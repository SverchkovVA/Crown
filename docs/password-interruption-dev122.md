# Аварийное завершение при смене фразы в dev122

Проверяются две точки на отдельной временной зашифрованной книге. Дочерний
процесс завершается сразу перед заменой ключевого файла либо сразу после,
без выполнения штатного закрытия и очистки. Затем основной процесс
открывает книгу заново и проверяет целостность, содержимое и PF1.

| Точка прерывания | Ожидаемое состояние |
|---|---|
| Перед публикацией | Действует прежняя парольная фраза |
| После публикации | Действует новая парольная фраза |
| В обоих случаях | Прежний PF1 работает, байты базы совпадают, блокировка освобождена ОС |

При прерывании до замены рядом с ключевым файлом может остаться
`.password-*.tmp` с зашифрованной обёрткой под новой фразой. Такой файл
не используется для открытия книги. Штатная ошибка записи удаляет свой
временный файл. Сценарий проверяет завершение процесса и не моделирует
физическое отключение питания.


На Windows 11 оба сценария прошли. Отчёт —
`artifacts/dev122-password-interruption.xml`.
