# Формат управляемого экспорта журнала — версия 1

Реализован в 0.2.0.dev8. Историческая подготовка чистого ядра в 0.2.0.dev7
проверялась отдельно; окончательные состав, русские заголовки, названия,
согласованный снимок и файловое сохранение описаны здесь. Формат экспорта
не меняет версию книги/ключей/резервной копии. [Результаты](stage-4-export-report.md).

## Выбор и снимок

`ExportSettings` содержит OperationQuery и include_names/include_notes/include_tags.
Названия включены по умолчанию, примечания и теги — нет. Период, счета, банки,
категории, виды, текст и теги выбирают текущие принятые операции. Удалённые
версии включаются явно. Перевод и разделённая операция сохраняются целиком:
сумма не пересчитывается по совпавшей категории. Внутри одной даты порядок UUID,
а не банковское время. История всех предшествующих версий не выгружается.

`Exporting.preview` читает операции/связи банков/названия одной транзакцией под
общим RLock. ExportPreview и его tuple названий неизменяемы. Сохранение использует
этот снимок даже после последующей правки. Внутренний source_book_id проверяет
принадлежность открытой книге, но не является полем файла. Названия справочников
за пределами выбранных ссылок не добавляются к результату.

## JSON

UTF-8, объект `format=crown-journal-export`, `version=1`,
`money_encoding=integer_minor_decimal_string`, массив `operations`.

| Поле | Значение |
|---|---|
| operation_id / revision_id | UUID операции и выбранной текущей версии |
| kind / date | opening/income/expense/transfer/refund и календарная ГГГГ-ММ-ДД |
| account_id / destination_account_id | Счёт и необязательный получатель перевода |
| currency / currency_exponent | Код валюты и число дробных знаков |
| amount_minor / fee_minor | Точные десятичные строки целых минимальных единиц |
| category_id / fee_category_id | Категория либо категория комиссии |
| parts | Части: category_id, строка amount_minor, необязательная category_name |
| refund_of / refund_of_revision_id | Необязательные UUID исходной покупки/версии |
| is_deleted | Признак удаления текущей версии |
| *_name | Названия счёта/банка/получателя/категорий при include_names=True |
| note | Только при include_notes=True |
| tag_ids / tag_names | Только при include_tags=True; имена также требуют include_names |

Деньги не превращаются в JSON float: это сохраняет int64 в потребителях без
точного большого integer-типа. Для RUB `"10000"` при exponent=2 — 100 рублей.
Ссылки могут вести к фактам вне частичной выборки; полный граф книги не создаётся.
Текст условий, имена книг, пароли/PF1 из хранилища, ключи, raw-импорт, пути,
реплики и квитанции не входят в набор полей.

## CSV

UTF-8 BOM, `;`, CRLF, русские заголовки, одна строка на операцию. Сначала дата,
вид и выбранные названия, затем читаемые «Сумма», «Валюта», «Комиссия». Суммы
выведены из целых без округления, десятичный знак — запятая. Вид — русский
вариант enum. Дополнительно сохраняются точные «Сумма, мин. ед.» / «Комиссия,
мин. ед.», точность валюты, UUID и связи; части/теги — JSON-ячейки.

Сумма — сумма операции, включая положительный расход с соответствующим видом,
а не движение со знаком одного банковского счёта. Перевод присутствует один
раз. Такой CSV не является банковской выпиской и не предназначен для обратного
импорта: сигнатура заголовков распознаётся банковским парсером и отклоняется.
Для переноса всей книги используйте проверенную зашифрованную копию.

Примечания/названия, начинающиеся с операторов формул после пробелов/переносов/
BOM, получают апостроф. JSON сохраняет выбранный исходный текст. CSV не задаёт
тип ячейки сторонней программы: большие точные значения следует импортировать
как текст, если её числовой тип не сохраняет все знаки.

## Предпросмотр и файл

GUI показывает общий состав/числа видов и до 200 первых строк. Файл содержит
всю выборку. До выбора нового имени ничего не записывается. Создание обычной
папки exports при открытии диалога сохранения не меняет финансовые факты книги.
Предлагается LocalAppData/PersonalFinance/exports; пользователь выбирает место.
Файл открытый, автоматической отправки нет. Сохранение внутри книги запрещено.

`write_export_new` создаёт собственное имя O_EXCL, записывает/flush/fsync,
публикует без замены через Windows rename либо POSIX link. Ошибка/коллизия
не удаляет чужое имя. Назначение-символическая ссылка запрещено. Закрытая сессия
или снимок другой книги отклоняются. Устойчивость реального накопителя при потере
питания и Windows ACL требуют отдельной проверки.

Экспорт доступен в 0003–0008 без миграции и не меняет таблиц/версий/балансов.
Самостоятельные наборы справочников, вклады/инвестиции и пакет ChatGPT остаются
следующим объёмом этапа 8. [ADR-0009](adr/0009-journal-export.md).
