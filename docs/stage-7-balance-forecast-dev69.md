# Прогноз остатка по счёту

12.11.2026. Кандидат Crown 0.2.0.dev69. Исходник `82bd7dd`.

В книге откройте «Отчёты → Календарь платежей…». Укажите период и счёт в RUB.
Добавьте ожидаемые доходы, покупки, подписки или проценты, затем нажмите
«Рассчитать». Вариант «Только календарь платежей» открывает прежний список
ожидаемых событий.

Начальный остаток считается по принятым проводкам до первого дня периода.
В таблице «По дням» отдельно показаны движения по журналу, ожидаемые платежи
и расчётный остаток к концу дня. Вкладка «Движения» показывает отдельные строки
и их источники. Период включает обе границы. Внутри дня берётся общий итог
движений, так как по датам нельзя установить порядок отдельных платежей.

Ожидаемая строка и проводка учитываются отдельно. Если они описывают один
платёж, уберите его из ожидаемых. Сценарные условия живут в памяти текущей
формы. Схема книги 0015, прогноз выполняется без записи финансовых операций.

Целевой набор с самопроверкой дал 33 passed. Нативные виды проверены в светлой
и тёмной темах при 100%, 125% и 150%. Источники и собранный EXE прошли нативную
самопроверку с локальным OCR, по 33 шага. SHA-256 EXE
`3fa5aa5314a6ccd6790f36e02a63bd872fef865fcd38ce522d14d9e264e92d73`.

Полный локальный набор прошёл, 2580 тестов. В
[CI](https://github.com/SverchkovVA/Crown/actions/runs/43224013996) по 2580
тестов прошли на Windows и Linux. Сверены исходник, SHA-256 четырёх технических
архивов, JUnit, JSON и логические идентификаторы тестов. Затронутая локальная
группа прошла повтор в системной временной папке после шести отказов Windows
при обратном переименовании каталогов временных книг на S:.
Ручная приёмка кандидата впереди.
