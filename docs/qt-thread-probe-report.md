## Финальное изменение

Измерительный код сохранял Python-обёртки QThread рабочих потоков и сравнивал
их позже в GUI. В обычных исходниках приложения currentThread не вызывается.
В шести GUI-модулях теперь сохраняется логический признак
[QThread.isMainThread](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QThread.html#PySide6.QtCore.QThread.isMainThread)
непосредственно во время работы. Проверка по-прежнему требует False для
каждого рабочего вызова. Проверки количества расчётов/чтений, результатов,
истории, финансовой неизменности и освобождения UI остаются.
В исходном сценарии дополнительно проверяется True в GUI-обработчиках.

Это устраняет удержание чужих Qt-объектов проверяющим кодом.
Внутренний механизм неправильной обёртки PySide детерминированно не доказан;
отдельное изменение тестового наблюдателя не считается общим исправлением Qt.
