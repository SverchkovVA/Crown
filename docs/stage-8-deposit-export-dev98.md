# Экспорт графика выплат вклада

В «Отчёты → Планирование» рассчитайте разовый или сохранённый прогноз.
Нажмите «Экспорт выплат…», выберите CSV или JSON и укажите новое имя файла.
Crown сохраняет даты, проценты, капитализацию и остаток из вкладки «Выплаты».
JSON дополнительно содержит границы срока, валюту и общие итоги. Суммы
в JSON записываются строками целых минимальных единиц. В CSV суммы
отображаются с десятичной запятой.

Это выгрузка сценарного расчёта. Название сохранённого сценария, ставки,
идентификаторы, движения счёта и фактические проводки в файл не входят.
Файл сохраняется локально вне книги. Повторный выбор существующего имени
отклоняется. Книга и денежный журнал не меняются.

Для проверки рассчитайте «Учебный вклад с изменением ставки», сохраните CSV
и JSON и сравните суммы трёх выплат с таблицей. Прошли 202 связанные проверки
на временных данных, включая открытие обоих экспортов через штатный интерфейс.
