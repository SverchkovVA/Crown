# Состав опубликованного портативного архива Windows

При проверке [CI dev125](https://github.com/SverchkovVA/Crown/actions/runs/43917216116)
ZIP `Crown-Windows-x64` содержал 1131 файл из 1132, записанных в ведомости
`app-payload.json`. В архиве отсутствовал `_internal/legal/.gitattributes`.
Это служебный файл Git с правилами хранения лицензионных текстов в репозитории.
В dev132 PyInstaller исключает его из списка поставляемых файлов.

Для сверки архива берутся портативный ZIP и технический архив `windows-check`
из одного запуска CI. Проверяется SHA-256 обоих ZIP и их связь с коммитом.
Затем сравниваются имя, размер и SHA-256 каждого файла в портативном ZIP с
`bundle/app-payload.json`. Ведомость сверяется с `build-result.json`. Такой
способ проверяет сохранность всех файлов, включая лицензионные тексты.
