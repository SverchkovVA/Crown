# Скорость расчёта доходности вклада — dev116

На длинном ряде движений вычисление приведённой стоимости повторяло возведение в
степень для каждой даты. Теперь используется схема Горнера по интервалам между
датами. Для каждого шага поиска степень множителя рассчитывается один раз для
каждого размера интервала.

Сверены 400 вымышленных рядов с нерегулярными датами. При точности Decimal 72
получены те же ставки. В диагностике на этом ПК медиана трёх замеров для ряда
из 10 000 движений уменьшилась с 7,156 до 0,701 с. Оба алгоритма запускались
попеременно на одном наборе. Результат измерения хранится локально в
`artifacts/dev116-deposit-yield-performance.json`.

Прошли 168 связанных тестов на Windows с нативным Qt, Ruff, форматирование и Mypy.

Нативные исходники, EXE и Windows Sandbox прошли по 34 шага самопроверки.
Гостевое окно запустилось без сети, Python и uv. В первом запуске испытательный
профиль указывал неверную дату каталога для отчёта. После исправления выполнен
полный гостевой прогон. [Полный CI](https://github.com/SverchkovVA/Crown/actions/runs/43750339873)
подтверждён для коммита 7f1a687. В Windows и Linux прошли по 2844 теста.
Сверены SHA-256 четырёх технических архивов, точный исходник, состав тестов
обеих платформ, JUnit и JSON сборки.
