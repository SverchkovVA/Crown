Отдельная подготовка OCR; рабочий комплект dev60 не изменён.
Точная связь двух DLL с Debian14-posix была установлена ранее.
Этот срез закрывает получение пяти точных исходных файлов из подписанного индекса.
Полная применимость лицензий и воспроизводимая пересборка остаются отдельными задачами.

## Проверенная цепочка

Повторно выполнена проверка Debian InRelease изолированным GnuPG2.4.9:
exit0, три прежних VALIDSIG. Использованы только сохранённые публичные ключи Debian;
загрузка ключей и запуск агента отключены. Пути переданы через cygpath,
поскольку Git GnuPG ожидает свой формат пути. Первая диагностическая попытка
с Windows-путём не нашла изолированный keyring и не была засчитана.

Из проверенного Release заново получены SHA-256 и размер Sources.xz.
Из него прочитаны именно gcc-14/14.2.0-19 и gcc-mingw-w64/27.
Все пять файлов этих записей фактически доступны и сверены по размеру и SHA-256.

## Выборочные исходники и уведомления

Вложенный gcc-14.2.0-dfsg.tar.xz прочитан потоком:140408 записей.
Четырнадцать выбранных файлов исходника/рецептов/уведомлений сохранены отдельно
с точными именами членов архива, размерами и SHA-256. Произвольные пути архива
на файловую систему не распаковывались.

COPYING.RUNTIME3324 байта имеет SHA-256
9d6b43ce4d8de0c878bf16b54d8e7a10d9bd42b75178153e3af6a815bdc90f74
и побайтно совпадает с [файлом официального тега GCC14.2.0](https://raw.githubusercontent.com/gcc-mirror/gcc/releases/gcc-14.2.0/COPYING.RUNTIME).
В выбранных libgcc2.c, unwind-seh.c и new_op.cc присутствует указание
GCC Runtime Library Exception3.1. Это выборочная проверка исходных уведомлений;
она не устанавливает условия каждого входящего в DLL файла.
[Руководство libstdc++](https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html)
отдельно описывает лицензирование кода и документации.

README.source пакета gcc-mingw-w64 описывает последовательное применение
series1, патчей gcc-source и series2. Эти рецепты сохранены, но патчи
не применялись; готовность точного patched-source и воспроизводимой сборки
не объявляется. Имеющийся copyright обёртки содержит старые ссылки gcc-9:
для версии использовались signed Sources, control и Built-Using, а не эта подпись.
