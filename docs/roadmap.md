# План реализации

Каждый значимый этап начинается после подтверждения пользователя.

| Этап | Статус и результат |
|---|---|
| 1 | Утверждён: исследование и архитектура |
| 2 | Утверждён: модель, контракты, UX, план и MVP |
| 3 | Автопрогон 0.1.2 Windows 11 и базовый ручной сценарий новой книги пройдены; старая книга, автономность, масштабы и чистая Windows остаются |
| 4 | Разрешён 26.10.2026. Первая поставка 0.2.0.dev1 в stage-4-ledger: ручной журнал, проводки, переводы, исправления/удаления, остатки на дату. 0.2.0.dev2 добавляет разделение и подробную историю, 0.2.0.dev3 — связанные возвраты (docs/stage-4-refund-report.md); полный этап не завершён |
| 4, расширение | Возвраты реализованы в проверочной поставке; остаются теги, фильтры, сверка, периоды, CSV/OFX; MVP 1.1 |
| 5 | Проверка OCR; тип A Т-Банк → тип B и остальные адаптеры |
| 6 | Вклады и накопительные счета, проценты, отчёты, графики |
| 7 | Бюджеты, цели, регулярные платежи, прогноз и финансовое состояние |
| 8 | Российские акции, облигации, БПИФ; сделки, выплаты, FIFO, доходность |
| 8, расширение | Котировки только кнопкой; полный экспорт; расширенные копии |
| 9 | Все обязательные функции Windows, типы A/B и Т-Банк/ВТБ/Яндекс Пэй, NSIS |
| 10 | Android Kotlin/Compose/Room, совместимые данные и согласованный интерфейс |
| 11 | QR, защищённая двусторонняя LAN-синхронизация и конфликтные сценарии |
| 12 | Построчная финальная приёмка каждого требования |

Идентификаторы и журнал появляются до сети. Копии уже присутствуют в основе;
реальные данные не допускаются только на основании Linux-проверок.

Для рынка закреплено: обновление по кнопке, сохранение цен офлайн, различение
цены за штуку/процента от номинала, НКД, источника и даты. MOEX ISS — кандидат;
условия доступа и использования должны быть подтверждены перед подключением.
Никакой источник и платная подписка пока не выбраны.
