# Проверка Windows-поставки dev128

Исходник `7a8f1bfe84478a11b4aed427e8939bce35671424`, отпечаток
`c001a7e00a972023f7367ee6194bb605f7555f73cbebb70bf1539020fa8c84e2`.
Из состава Windows-поставки ушли ровно два файла. Это сетевой адаптер ввода
TUIO и его библиотека Qt6Network. Размер каталога уменьшился на 1883138 байт.
Все 105 оставшихся нативных файлов совпали с входами PyInstaller, 77 из них
также с SHA-256 в `RECORD` установленных wheel.
[Измерение состава](stage-9-windows-native-origins.md)

Windows PowerShell 5.1 собрал 1130 файлов. В Windows Sandbox без сети, Python
и uv обычный пользователь установил dev128. Гость сверил все 1130 файлов.
Установленный EXE прошёл 33 шага, затем приложение удалено через штатную
команду из списка программ Windows. Сохранены учебные книги 0002 и 0018,
отдельная зашифрованная копия и соседняя папка версии. Проверено 10 шагов
сценария установки и удаления.

Самопроверка исходника и портативного EXE с отдельным локальным OCR прошла
по 35 шагов. В портативной проверке использовались синтетические изображения
и книга. Для обычной установки собрана базовая поставка без добавочного
комплекта OCR. [GitHub CI](https://github.com/SverchkovVA/Crown/actions/runs/43922758827)

Для ручной проверки в портативном кандидате достаточно открыть уже имеющуюся
тестовую книгу, убедиться, что видны операции и отчёт, закрыть книгу и открыть
снова. Для OCR выбрать синтетическую карточку и историю и сверить предложения
без записи. Поддерживаются схемы 0002–0018. При открытии схема сохраняется.
