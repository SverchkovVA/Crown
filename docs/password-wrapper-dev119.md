# Подготовка смены парольной фразы в dev119

Парольная фраза защищает обёртку случайного ключа SQLCipher. Для смены фразы
компонент проверяет действующую фразу, UUID книги и совпадение ключа с открытой
сессией. Затем готовит обёртку v1 с новой солью Argon2id и шифротекстом
XChaCha20-Poly1305. Поле восстановления PF1 переносится после проверки его
структуры. Старый код восстановления продолжает открывать ту же книгу.

Компонент формирует байты в памяти. Запись ключевого файла и интерфейс
проверяются в следующих срезах. Прошли шесть связанных проверок на
вымышленных ключах, включая ошибочную фразу, несовпадающие UUID или ключ,
повреждённую структуру PF1 и сохранение внешних пробелов новой фразы.
