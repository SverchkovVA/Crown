# Проверка ведомости обновления Windows

В dev129 подготовлен локальный инструмент разработчика
`tools.windows_release_manifest`. Он проверяет файл установщика и подписанную
ведомость. Приложение пока не содержит интерфейса обновлений.

Ведомость UTF-8 содержит `format`, `platform`, `version`, `expires_utc`,
`installer_bytes`, `installer_sha256` и `source_sha256`. Первая версия
формата предназначена для стабильных выпусков Windows x64. Подпись Ed25519
проверяется по исходным байтам до разбора JSON. Открытый ключ нужно получить
от издателя по независимому доверенному каналу. Отдельный файл подписи
содержит 64 байта, файл открытого ключа — 32 байта.

Перед принятием обновления проверяется, что версия новее переданной
доверенной версии, а срок действия ещё не истёк. Имя EXE выводится из версии,
а размер и SHA-256 сверяются с подписанной ведомостью. Доверенная нижняя
граница версии должна поступать из состояния клиента. Этот инструмент
принимает её как явный аргумент для локальной проверки.
[Проверка подписей PyNaCl](https://pynacl.readthedocs.io/en/latest/signing/),
[угрозы отката и заморозки обновлений](https://theupdateframework.github.io/specification/latest/index.html)

Команда разработчика после подготовки подписанного издателем пакета.

```powershell
uv run --frozen python -m tools.windows_release_manifest `
  --manifest .\release.json `
  --signature .\release.sig `
  --public-key .\publisher.pub `
  --minimum-version 0.2.0 `
  --installer .\Crown-0.2.1-windows-x64-setup.exe
```

21 компонентный тест проверяет исправный пакет, замену файла и ключа,
дубликаты полей, неподдерживаемую платформу, откат и истечение срока
действия. Использовались искусственные пары ключей и файлы.

Для выпуска нужна доверенная подпись самого EXE в дополнение к подписи
ведомости. После подписания и отметки времени нужно пересчитать SHA-256
установщика. Распространение открытого ключа, его замена и отзыв, место
публикации и способ передачи обновления приложению остаются отдельными
решениями. Учебная проверка формата Authenticode проведена на dev126.
