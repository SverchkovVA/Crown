# Следующий срез этапа 6: графики отчёта

29.10.2026. План следующего независимого read-only среза после полного прогона
[dev15](stage-6-sources-report.md). Это не реализованные функции и не приёмка.
Основание: требования 5.5.01/5.5.03 и заранее согласованный Matplotlib.

## Границы

Одна дополнительная вкладка отчёта: динамика доходов/расходов по месяцам и
структура расходов по категориям. Исходные данные — тот же IncomeExpenseReport,
не новый запрос к книге. Валюта выбирается явно; разные валюты не складываются.
Пустой снимок показывает понятное сообщение, без фиктивной валюты/месяца.
Числа и подписи берутся из точных int; финансовые расчёты/хранение не меняются.
Низкоуровневые координаты отрисовки не используются как финансовые значения.
Точные подписи/таблицы сохраняются и при суммах, превышающих точность координат.

Возврат прошлого месяца может дать отрицательный расход: нужны столбцы с нулевой
линией, а не круговая диаграмма с недопустимыми отрицательными секторами.
Начальные остатки и свой перевод исключены; комиссия остаётся расходом.
Категории с возвратами не исчезают и не превращаются в доход. Цвета дополнены
названиями/легендой; таблицы остаются доступным точным представлением.
Из выбранного месяца/категории можно открыть уже реализованные источники снимка.
Нет финансовой записи, новых таблиц, внешней сети, автоматического экспорта,
панели сохранения Matplotlib, смены стека или подключения OCR 0012.

## Интеграция и первичные источники

Проверенный кандидат — matplotlib==3.11.2 (CPython 3.13 Windows x64):
[PyPI](https://pypi.org/project/matplotlib/3.11.2/).
Использовать собственный Figure и FigureCanvasQTAgg с предварительным импортом
PySide6, без pyplot/global backend switch или таймеров обновления:
[официальное встраивание Qt](https://matplotlib.org/stable/gallery/user_interfaces/embedding_in_qt_sgskip.html).
В PyInstaller явно собирать только QtAgg, не тянуть Tk/другой Qt:
[настройка hook](https://pyinstaller.org/en/stable/hooks-config.html#matplotlib-hooks).
Надписи пользователя считать обычным текстом, отключить MathText/TeX.
Зависимости менять только после окончания активного локального прогона;
сверить старые версии в uv.lock, новые лицензии и минимальный frozen install.
Проверить font/data/DLL в собранном EXE; source-тест не доказывает поставку QtAgg.

## Критерии завершения среза

- Таблицы/графики используют один снимок и согласованные суммы/валюты/категории.
- Покрыты части, комиссия, отрицательный расход, пустота, другая валюта и большие int.
- Подписи дают точные суммы, а выделение/переход сохраняет контекст источников.
- Закрытие окна освобождает canvas, повторное открытие не множит сигналы/виджеты.
- Локальный полный прогон, source/EXE-самопроверки, CI Linux/Windows и скрытый
  нативный осмотр на вымышленных данных выполнены для нового отпечатка исходников.
- Обычный EXE автономно показывает график без установленного Python/Matplotlib
  в PATH; это ограниченная изолированная проверка, не чистая Windows без Python.
- Документация указывает фактический статус; банки/даты/пользовательские данные
  в тестовый набор или отчёты CI не попадают.

После этого отдельно остаются сравнения периодов, фильтры счетов/банков при
построении, балансы/денежные потоки и вклады/проценты. Общая аналитика этапа 6
не считается готовой по одному отчёту или графику.
