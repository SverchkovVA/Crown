# Корпоративные события в пробной книге 0018

У инвестиционной позиции сохраняются события своего инструмента.
Для акции доступно целое прямое дробление. Для облигации —
частичное погашение номинала. В пробной схеме 0018 каждое изменение
сохраняется новой версией. Дата и порядок внутри дня определяют,
когда событие участвует в вычислении. Версии доступны из списка
сохранённых позиций.

В отчёте портфеля дата учитывает актуальное количество и себестоимость.
Сверка показывает ожидаемое денежное поступление при частичном погашении
и ищет кандидатов по счёту, валюте, дате и сумме. Эта проверка
сопоставляет уже существующие записи. Документ брокера нужен для
подтверждения найденного кандидата.

Штатная версия сохраняет схему 0017, где оба события рассчитываются как
черновики. Сохранение и повторное открытие 0018 проверяются на временных
книгах. Рабочая схема будет решаться отдельно после сквозной матрицы,
сборки, проверки автономного запуска и полного CI. Устройство форматов
и проверка восстановления описаны в [отчёте dev104](stage-8-bond-amortization-storage-dev104.md).

Dev106 включает оба черновых расчёта в самопроверку исходников и EXE.
При дроблении проверяются количество, неизменная себестоимость и
исключение цены прежней единицы. При частичном погашении проверяются
возврат номинала, остаток себестоимости, отдельный результат и запрет
цены с прежним номиналом. Самопроверка проверяет отображение обоих
событий и целостность временной книги после построения отчётов.
