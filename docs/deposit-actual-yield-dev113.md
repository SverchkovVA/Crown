# Фактическая доходность вклада — расчётный компонент dev113

Требование 5.3.04. Сценарий «План и факт» уже сравнивает суммы процентов по счёту,
категории и дате. Для фактической годовой доходности нужен отдельный набор
подтверждённых денежных движений. В него входят внесённые деньги, выплаты и
подтверждённый остаток на дату среза, если вклад ещё открыт.

Подготовлен расчёт годовой внутренней нормы доходности по датированным потокам.
Входные суммы остаются целыми минимальными единицами. Для расчёта применён
`Decimal` с собственной точностью. Дни календарные, длительность года в формуле
365 дней. Движения одного дня складываются. Сумма зачисленных процентов из
существующего отчёта сама по себе не определяет доходность.

В компоненте поддержана последовательность с одним переходом знака: внесения,
затем выплаты. Она даёт единственный корень. Если после начала выплат есть новое
внесение, компонент отклоняет такой ряд без выбора произвольного корня.
Результат относится только к переданным потокам.

Формат расчёта сопоставлялся с описанием [XIRR в Microsoft Support](https://support.microsoft.com/en-us/excel/functions/xirr-function)
и с объяснением внутренней нормы доходности в [справочнике GIPS](https://www.gipsstandards.org/standards/gips-standards-for-asset-owners/gips-standards-handbook-for-asset-owners/).

В этой версии компонент ещё не подключён к отчёту. Для следующего среза нужна
явная привязка записей журнала к одному вкладу и подтверждение остатка. Условия
прогноза и текущие версии операций сами не меняются. Штатная схема 0018.


Связанный набор — 162 пройденных теста, включая расчёт вкладов, отчёт, метаданные
и нативную GUI-проверку старых сценариев. Ruff, форматирование и Mypy прошли.
Опубликованный пример XIRR сверён в пределах 0,000001 процентного пункта.
Невязка уравнения проверена независимо с повышенной точностью.
