Параметр `-ParallelTests` в `verify.ps1` запускает две группы с отдельными
временными папками, pytest-логами, манифестами и JUnit. Общий JUnit
публикуется после успеха обеих групп и проверки полного непересекающегося
набора. Время и полный прогон Windows-сборки по-прежнему проверяются.
Обычный запуск `verify.ps1` сохраняет последовательный режим.
