# Пробный зашифрованный кэш котировок

В dev109 подготовлена отдельная миграция 0019. Она добавляет кэш
котировок в SQLCipher. Ключ записи включает книгу, поставщика,
инструмент, режим торгов и календарную дату. В записи есть момент
котировки в UTC, точная десятичная цена, валюта и единица расчёта.
Номинал и НКД облигации сохраняются целыми минимальными единицами.

Приложение может прочитать последнюю подходящую цену на выбранную дату.
Котировка другого режима не подменяет выбранную. В транзакции
повторно проверяется свежесть строки. Если более свежий результат уже
записан, запоздавшее обновление оставляет его в кэше. Для одной даты
хранится один подтверждённый вариант. Более ранние даты сохраняются
для офлайн-оценки. Ошибочная привязка откатывает незавершённый пакет.

Миграция испытывается с временной базой. Обычные новые и восстановленные
книги этой ветки используют 0018. Работающий путь чтения, запись и старые
книги проверяются отдельно перед активацией. Сроки использования данных
и выбор источника зависят от условий поставщика.
[Сравнение источников](stage-8-price-sources.md).
