# Прогресс цели по остатку счёта в dev117

В открытой книге перейдите в «Отчёты → Сохранённые бюджеты и цели…» и выберите
сохранённую цель. Нажмите «Рассчитать», затем «По остатку счёта…». Выберите
счёт, деньги на котором выделены на эту цель. Дата расчёта берётся из
выбранной версии условий.

Прогресс и прогноз используют денежный остаток этого счёта на конец указанного
дня. Прошлые движения входят в остаток. Учитываются комиссии по этому счёту.
Из «Движений счёта» можно открыть исходную версию каждой включённой операции.
Счёт без движений даёт нулевой прогресс. При отрицательном остатке форма
предлагает выбрать другой счёт.

Выбор действует для открытого расчёта. Постоянные назначения счетов и
операций к целям, история прогресса и изменение схемы в этот срез не входят.

## Ручная проверка

В отдельной учебной книге сохраните цель на 31.01.2026 с накоплением 100,00 RUB,
суммой цели 300,00 RUB и пополнением 100,00 RUB в месяц. Запишите 209,00 RUB на
учебном счёте на ту же дату. Обычный расчёт покажет 33,33%, расчёт по счёту
покажет 69,66%. Откройте «Движения счёта» и проверьте версию операции.
Вернитесь в обычный расчёт и убедитесь, что он по-прежнему показывает 33,33%.

## Проверки

По 29 связанных тестов прошли в Qt Windows и Qt offscreen. Нативная компоновка
выбора счёта и отчёта проверена при 100%, 125% и 150% в обеих темах.

Чтение четырёх временных книг 0015–0018 дало тот же остаток и сохранило
побайтные хеши книги. Ruff, проверка форматирования и Mypy прошли. Сборка Windows,
нативные самопроверки исходников и EXE, а также фоновая проверка в Windows Sandbox
прошли по 34 шага с локальным OCR. В госте подтверждено отсутствие маршрута по
умолчанию, Python и uv. Интерактивный сеанс приложения проверен на основной Windows.
