# OCR dev56: границы источника суммы

06.11.2026. Основа — проверенный dev55/606512e. Пользователь сообщил, что ручная проверка dev55 прошла без замечаний. Это не подтверждает отдельные проверки DPI, автономности и чистой Windows.

Найден дефект: универсальный адаптер проверял только нижний край суммы, а опытные карточки не проверяли края. Область суммы у верхнего или бокового края могла пройти к финансовой подготовке. Предусмотренная контрактом неполнота источника должна блокировать запись и при отключённых флажках подтверждения.

Выбран общий контроль четырёх границ с прежним отступом 8 пикселей включительно. Проверяются только исходные слова суммы. Поля и документ остаются неизменными; пользователю предлагается полный снимок. Существующие причины отказа сохраняют приоритет. Объединённые повторные суммы ВТБ проверяются после объединения источников. Знак, цифры, валюту и дату не угадывать.

Порядок: воспроизведение отрицательными тестами; общая проверка источника; проверки отсутствия финансовой записи и атомарности пакета; замороженные OCR-выборки; полный набор тестов, сборка, source/EXE и оба CI. Версии адаптеров меняются для нового контекста, прежний аудит не переписывается. Схема 0014 и зависимости прежние.
