# Запись новой парольной фразы в dev120

Разблокированная сессия проверяет текущую фразу, идентификатор книги и ключ
открытой базы. Смена фразы обновляет только парольную обёртку в `data/key.json`.
Данные, идентификатор, формат ключевого файла и обёртка PF1 сохраняются.
Код PF1 продолжает действовать. У резервной копии своя парольная фраза.

Сессия держит блокировку книги. Запись идёт во временный файл рядом с ключевым
файлом. До записи копируются права доступа. Windows сохраняет владельца,
группу, правила DACL и защиту от наследования. На POSIX сохраняются владелец,
группа и режим файла. Перед заменой приложение сбрасывает буфер файла и
проверяет, что исходный ключевой файл имеет прежнее содержимое. При ошибке
до замены исходный файл остаётся в силе. После замены на POSIX отдельно
проверяется сброс буфера каталога.

Это прикладной сценарий для открытой книги, без изменений формата хранилища.
Кнопка и форма появятся в отдельном срезе. Восстановление продолжается по PF1
или отдельному зашифрованному архиву.

Реализация переноса прав опирается на документацию
[дескрипторов безопасности Windows](https://learn.microsoft.com/en-us/windows/win32/secauthz/security-information).
