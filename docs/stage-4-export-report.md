# Управляемый экспорт журнала — 0.2.0.dev8

Часть требования 5.13 в разрешённом этапе 4, ветка stage-4-ledger.
Main сохраняет 0.1.2. [Предыдущий импорт](stage-4-import-report.md).
Только синтетические проверки; полный этап и ручная приёмка ещё не завершены.

## Реализовано

Кнопка «Экспорт…»: формат CSV/JSON, существующие условия журнала, выбор названий/
примечаний/тегов, просмотр состава и сохранение нового открытого файла. Названия
включены по умолчанию, примечания/теги — нет. Даты/счета/банки/категории/виды/текст/
теги отбирают целые операции, не меняют суммы частей/перевода и балансы.
Удалённые версии включаются явно. Предпросмотр показывает до 200 строк, файл — всю
выборку. [Формат v1](export-format-draft.md), [ADR-0009](adr/0009-journal-export.md).

Согласованные текущие версии, банковские связи и названия читаются одним
SQL-снимком/RLock. Сохраняется просмотренный immutable-снимок, последующая правка
его не меняет. Закрытая сессия и чужая книга отклоняются. UUID привязки не
попадает в файл. Экспорт не записывает версии, проводки, квитанции и остатки.

JSON хранит деньги строками целых минимальных единиц с кодом/точностью валюты.
CSV UTF-8 BOM/`;`/CRLF: русские заголовки/виды, читаемые суммы из целых и точные
минимальные единицы, UUID/связи и JSON-ячейки частей/тегов. Названия и примечания
защищены от CSV-формул; JSON сохраняет выбранный исходный текст. В файле нет
ключей/паролей из хранилища, raw-импорта, путей или реплик.

Предлагается локальная AppData/PersonalFinance/exports; пользователь выбирает
место. Сохранение внутри книги и замена чужого файла запрещены. Временное имя
создаётся исключительно этим вызовом, запись flush/fsync, публикация без замены.
При коллизии временного имени чужой файл сохраняется. Формат собственного CSV
журнала распознаётся банковским парсером и отклоняется: это не банковская
выписка со знаками движений. Простое банковское «ID операции» по-прежнему принимается.

## Совместимость

Схема остаётся 0008, новых миграций нет. Экспорт доступен в 0003–0008 без
обновления книги; в 0002 отключён. Восстановление/форматы ключей/копий и старые
финансовые хеши неизменны. uv.lock меняет только версию локального пакета.

## Границы

[Ручной сценарий Windows](windows-quickstart.md#управляемый-экспорт--020dev8).
Пока экспортируется журнал, без самостоятельных наборов справочников, вкладов,
инвестиций, полной истории или пакета ChatGPT (этап 8). Открытый CSV/JSON не
является резервной копией и не поддерживает обратное восстановление книги.
Реальные отключения питания, Windows ACL и работа на чистой Windows без Python
не доказаны. Прежняя ручная приёмка этапа 3, конкретные банковские CSV/OFX и
ручная проверка новых функций остаются неполными. OCR ещё не начат.
