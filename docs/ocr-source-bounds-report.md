# OCR dev56: полнота строки суммы

06.11.2026. Окончательный исходник751dcc27430737e2612788e6b4532b3adc8146c3,
ветка ocr-source-bounds-dev56, worktree artifacts/worktree-ocr-dev56.
Отпечаток исходников/тестов/упаковки:
3a4ee4e20199c2c2a3ec45e857b7a74f37e21606cad9595231fcde21fd8d41a8.

Проверяются все четыре края с прежним отступом8 пикселей включительно.
Примыкающая неизвестная валюта тоже участвует в проверке полноты, даже если
движок разделил её на слова или строки. Отделённые надписи не блокируют сумму.
Поля, координаты и документ не исправляются; нужна полная картинка.
При отключённых подтверждениях неполная строка всё равно не записывается.
Пакет с принудительно выбранной неполной строкой ничего не пишет; после её
исключения сохраняется только полная строка, повтор не создаёт дубль.

Версии адаптеров: generic-card-v11, generic-history-v9, t-bank-card-v2,
vtb-card-v2, vtb-history-v2. Исторический аудит не переписывается;
для прежнего generic-card-v10 добавлена проверка конфликта нового контекста.
Схема0014, финансовые/криптографические форматы и зависимости прежние.

## Границы

всего снимка. Если отрезанная часть совсем не дала слова/связного фрагмента,
её наличие по координатам восстановить нельзя. Полностью отсутствующие знаки
и цифры не угадываются. Банковская точность этим синтетическим набором не измерена.
