local_tag_signature_verified=false. Личный keyring не использовался.

## Что известно о сборке

В проверенном исходнике найдены
[workflow Windows-installer](https://github.com/tesseract-ocr/tesseract/blob/db0ec62f81b0737fbbe184d8fea40af5738f8eef/.github/workflows/installer-for-windows.yml)
и [nsis/build.sh](https://github.com/tesseract-ocr/tesseract/blob/db0ec62f81b0737fbbe184d8fea40af5738f8eef/nsis/build.sh).
Это ручной workflow_dispatch с ubuntu-24.04; он вызывает build.sh.
Рецепт обращается к текущим apt/pacman-репозиториям и незакреплённым веткам
MSYS2-keyring/mirrorlist, версия pip pefile также не закреплена.
Поэтому одного рецепта недостаточно для восстановления точной среды конкретного бинарного файла.

Из API сохранены25 доступных запусков с точным head_sha тега.
Среди них нет Cross build for Windows. Это отсутствие в конкретной полученной
коллекции; оно не доказывает, что сборки никогда не было или что установщик
получен из другого исходника. Привязка бинарного asset к конкретной сборке
по-прежнему не подтверждена. Релиз не immutable.

Asset488782593 имеет опубликованный SHA-256
bee9e3434bd94fd65387d9be28cd467a41f61b1275383b55b0f59a1331270ae4,
который ранее побайтно сверялся с сохранённым установщиком.
Совпадение всех56 его нативных файлов с runtime подтверждено отдельно.
Эта цепочка относится к опубликованным байтам установщика,
а исходная сборка остаётся отдельным открытым вопросом.
