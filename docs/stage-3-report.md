# Отчёт этапа 3

Дата: 25.10.2026. Среда разработки: Linux x86_64, CPython 3.13.16.
Исходная основа 0.1.0 дополнена в 0.1.1 сценарием проверки Windows и безопасными
отчётами самопроверки. Windows-среда по-прежнему недоступна.

Проверяются исходники, точные типы, защищённое хранилище, миграции, справочники,
резервирование, аварийные сценарии и интерфейс без экрана.

В установленном Linux-пакете: SQLCipher 4.19.0 Community и SQLite 3.53.4.
PyInstaller-каталог занимает примерно 206 MiB; это измерение Linux, не оценка
размера будущего Windows-дистрибутива.

Самопроверка выполняет создание, добавление счёта, резервирование, восстановление
и открытие окна на временных данных. Тесты дополнительно проверяют неверные
пароли, повреждения, повтор команды, атомарность, остановку процесса, хеши версий,
эксклюзивность книги и автономный сценарий с запрещёнными Python-сокетами.

## Остаётся проверить

- Запуск, тесты и сборка непосредственно на Windows 11 x64.
- Каталог приложения на чистой Windows без Python.
- ACL, нативные диалоги, масштабирование и поведение файловой системы Windows.
- Реальные сбои питания, нехватка места и недоступный носитель.
- Полные лицензии транзитивных бинарных зависимостей перед распространением.

Автоматические Windows-проверки описаны в GitHub workflow, но не запускались.
Удалённый репозиторий не создавался, код не отправлялся.

## Подготовка Windows-проверки в 0.1.1

- Проверены синтаксис и помощники запуска в PowerShell 7.6.9 на Linux.
- Проверены кавычки, пустые аргументы, кириллица, пробелы, большие stdout/stderr,
  ненулевой код возврата и принудительное завершение по тайм-ауту.
- Проверен отказ verify.ps1 на Linux: unsupported_platform, пустой список
  выполненных Windows-шагов, stage3_complete=false; установка и сборка не запускались.
- Тесты JSON-отчёта проверяют правдивый статус платформы, отсутствие секретов,
  сообщение о сбое конкретного шага и запрет замены существующего файла.
- Самопроверка использует кириллицу и пробелы в путях, проверяет код восстановления,
  неверный пароль, копию, новую реплику и очистку окна при закрытии.
- Повторная самопроверка упакованной 0.1.1 прошла восемь шагов; JSON подтверждает
  platform=linux, frozen=true и windows11_manual_acceptance=pending.

Исполнение PowerShell 5.1, Windows DLL и нативных окон не проверено. Проверка
помощников на Linux не заменяет прогон check-windows.cmd на целевой машине.
