## Первый пользовательский прогон Windows

Начало: 25.10.2026, 21:04 UTC (26.10.2026 МСК). По переданным пользователем
`report.json` и журналам:

- Windows 11 x64, build 26300, PowerShell 5.1.26100.9711.
- uv 0.13.5 успешно установил зафиксированные зависимости.
- Python 3.13.16, Qt 6.12.0, SQLCipher 4.19.0, SQLite 3.53.4 успешно импортированы.
- Отпечаток исходников совпал с переданной версией 0.1.1.
- Проверка остановилась на `03-process-helpers`: «Изменилось число аргументов».
  Тесты Python, самопроверки и сборка ещё не запускались.

Причина в тесте: `@(… | ConvertFrom-Json)` добавляет внешний массив в PowerShell
5.1. Проверка теперь присваивает результат типизированному массиву без обёртки.
Добавлена проверка кириллицы в stdout/stderr собственного дочернего PowerShell;
его кодировка UTF-8 задана явно. Локальный прогон PowerShell 7.6.9 прошёл.
[Прогон CI #1](https://github.com/SverchkovVA/Crown/actions/runs/40234841296)
подтвердил исправление в PowerShell 5.1: помощники, Ruff и Mypy прошли.
Python-тесты: 47 прошли, один выявил отказ повторного открытия книги сразу
после принудительного завершения дочернего процесса. Добавлено ограниченное
ожидание системной блокировки до двух секунд; проверка также требует отказа
для ещё живого дочернего процесса. Повторный локальный прогон: 48 passed,
27,01 с. Подтверждение исправления на Windows ожидается в следующем CI-прогоне.

Исходные пользовательские отчёт и журналы в Git не включаются. Проект отправлен
в [SverchkovVA/Crown](https://github.com/SverchkovVA/Crown) с сохранением начального
коммита репозитория и истории разработки. CI сохраняет только отчёты и журналы
своих прогонов на синтетических данных.
