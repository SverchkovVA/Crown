# Состав Windows-каталога dev112

15.11.2026, исходник `017b310b54694dcfd128986f1a28fa2b3d934314`.
Проверена локальная сборка каталога PyInstaller на Windows 11 x64. SHA-256
`PersonalFinance.exe` —
`cffb1f2ac440c44db42e1fa6e49a553106d39564d48b890bcf9bf9977fab051b`.

В базовом каталоге 1132 файла (178 708 761 байт). Список совпал с
`COLLECT-00.toc`. Для 107 файлов PE32+ AMD64 сопоставлены относительный путь,
источник и SHA-256. Все 107 файлов побайтно совпали со входами PyInstaller.
Из них 27 связаны с установленным CPython, 79 с Python-пакетами по их
`RECORD` и один с результатом локальной сборки. В `_internal/legal`
находятся 39 файлов. Добавленный отдельно комплект OCR сверён по закреплённому
манифесту — 56 нативных файлов и две языковые модели.

В каталог фактически попадают следующие библиотеки:

| Файл | Статическая зависимость в каталоге |
|---|---|
| `Qt6Network.dll` | Плагин Qt `qtuiotouchplugin.dll` |
| `libcrypto-3-x64.dll` | `_hashlib.pyd`, `_ssl.pyd`, `libssl-3-x64.dll` |
| `libssl-3-x64.dll` | `_ssl.pyd` |

Фраза в `THIRD_PARTY_NOTICES.md` о сетевом модуле Qt описывает использование
в приложении. Для состава дистрибутива следует учитывать, что DLL Qt Network
попадает в него транзитивно. Инвентаризация охватывает обычные и отложенные
импорты PE. Вызовы динамической загрузки, применимость условий лицензий и
полнота уведомлений публичной поставки требуют отдельной проверки.
Установщик и цифровая подпись этим шагом не создавались.
