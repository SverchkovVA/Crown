# Вложенные исходники MSYS2 — 06.11.2026

Отдельная подготовка доставки OCR. Приложение и его58 файлов runtime не менялись.
[Исходные архивы MSYS2](https://repo.msys2.org/mingw/sources/) уже были связаны
с точно совпавшими бинарными пакетами через подписи и SHA-256 PKGBUILD из BUILDINFO.
В этом срезе прочитаны вложенные исходники и патчи всех41 пакета.

## Что проверено

Архив и detached-подпись каждого пакета повторно сверены по сохранённому SHA-256.
Прежний результат криптографической проверки унаследован только после совпадения
этих байтов; новые GPG-проверки всех41 подписей в этом проходе не выполнялись.

tar.exe преобразовывал пакет в поток tar, Python читал только заголовки и байты.
Файлы не распаковывались в приложение; пути проверялись, ссылки не разыменовывались,
члены/объём и время процесса ограничены. PKGBUILD не исполнялся.
Из checksum-массивов прочитаны только литералы и SKIP, без shell-подстановок.

Результат:41/41 пакет измерен,156 вложенных файлов кроме PKGBUILD/SRCINFO.
У120 файлов фактический digest совпал с литералом соответствующего checksum-массива.
Остальные36:13 detached upstream-подписей,22 файла Git-кеша winpthreads
и один install-hook fontconfig. SKIP-токенов13, нелитеральных checksum-массивов0.

Это совпадение содержимого с опубликованными checksum-литералами.
Позиционная привязка каждого URL/подстановки source к массиву не исполнялась
и не объявляется завершённой.

## VCS-исходник winpthreads

Из PKGBUILD прочитан точный commit d999af62247693a8b5b25a98d67316c8bb2dcd37.
В новом bare Git-репозитории использованы только два файла pack/idx из
проверенного исходного архива. Конфигурация и hooks архива не копировались;
личная и системная Git-конфигурация отключены, сеть не использовалась.

git fsck --full --strict завершился с exit0. Нужный commit и дерево существуют:
tree7abb564b2fccabe4ab0e2d32bb822d7fe0d2bb82.

закреплённого дерева; они не выдаются за22 отдельных upstream-архива.
