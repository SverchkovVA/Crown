## Поведение

Из окна результата «Изменить условия» возвращает **ту же** живую форму.
Суммы, даты, политики, таблицы изменений и UUID остаются. Следующий расчёт
выполняется в worker; предыдущий frozen результат остаётся прежним.
Закрытие результата завершает сеанс, отмена формы не запускает повторный расчёт.
Ошибка расчёта возвращает ту же форму с понятным сообщением без технических данных.
Результат предлагает редактирование только когда у вызывающего окна есть форма:
в standalone диалоге этой кнопки по умолчанию нет.

Контроллер освобождает форму после завершения сеанса, результат — после каждого
просмотра; исключение окна также не оставляет их жить. Начальный UUID ставки
создаётся один раз на форму, а не при каждом нажатии «Рассчитать». Условия
на диске не сохраняются. Отклонённая активация хранения 0013 этим не обходится.
