# Предварительный установщик dev125

Сборка NSIS размещает Crown для текущего пользователя в
`%LOCALAPPDATA%\Programs\Crown\0.2.0.dev125`. У каждой версии свой каталог,
ярлык в меню «Пуск» и запись в списке программ. Сценарий проверяет место
назначения и сначала извлекает пакет во временный каталог на том же томе.
Установщик создаёт окончательное имя после извлечения всех файлов.

При удалении список поставленных файлов берётся из сборки. Сценарий
проверяет папки на точки повторной обработки и первым удаляет главный EXE.
Открытый Windows файл не позволяет продолжить удаление. Папки удаляются
только пустыми, пользовательские книги, копии и настройки сохраняются.
[Команды NSIS](https://nsis.sourceforge.io/Docs/Chapter4.html),
[блокировки файлов Windows](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-deletefilew).

## Сборка разработчика

1. Установить закреплённые зависимости через `uv sync --frozen`.
2. Выполнить `packaging/windows/build.ps1` в новый каталог и сохранить
   `build-result.json` и `app-payload.json`.
3. Получить переносимый ZIP NSIS 3.13. Сценарий сверяет опубликованный
   SHA-256 `ba63dffc4410ee89193e1cb5a41989991bd77c61068da17e3156d136b7b0b3d8`
   до распаковки. [Выпуск NSIS](https://sourceforge.net/projects/nsis/files/NSIS%203/3.13/nsis-3.13.zip/download)
4. Под Windows PowerShell 5.1 запустить `packaging/windows/build-installer.ps1`
   с параметрами `-BuildDirectory`, `-NsisArchive` и `-OutputDirectory`.
   Последний путь должен быть новым. Скрипт повторно сверяет каждый файл,
   собирает установщик и сохраняет версию и SHA-256 в `installer-build.json`.

В сборку входит обычный каталог PyInstaller. В папке установленной версии
есть текст лицензии использованного NSIS. Книги используют существующий
формат 0018 с поддержкой открытия 0002–0018. Цифровая подпись выпуска,
модуль OCR для общего распространения и система обновлений остаются в плане.

На Windows собран установщик из 1132 файлов, прошли 12 связанных тестов.
Исходная самопроверка выполнена с локальным OCR. Для установки и удаления
готовится отдельный опыт в Windows Sandbox без сети и доступа к пользовательским
папкам книги.
