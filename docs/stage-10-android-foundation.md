# Первый рабочий срез Android

17.11.2026 пользователь подтвердил работу проверочных сценариев Windows и
попросил начать мобильное приложение. Android развивается в отдельном
Gradle-проекте `android/` на согласованных Kotlin, Compose и Room.

## Объём

- «Операции» показывает доходы, расходы, переводы и остаток за учебный месяц.
- «Счета» показывает остаток каждого счёта. Нажатие открывает журнал этого счёта.
- Карточка операции показывает дату, сумму и счета, а для перевода с комиссией —
  её отдельно. Суммы хранятся в целых копейках.
- Светлая и тёмная темы следуют системе. На узком экране и с крупным шрифтом
  сумма располагается под описанием.
- Встроенная учебная выборка загружается в Room в памяти. Это позволяет
  проверить чтение, транзакции и интерфейс до подключения зашифрованной
  пользовательской книги. Источник данных — единственный синтетический JSON
  из `shared/android-fixtures/`, который сверяется с проводками Windows.
- Приложение работает локально. Установлен параметр Android `allowBackup=false`.
  Для хранения пользовательских данных предстоит реализовать шифрованную
  мобильную книгу с привязкой ключей к Android Keystore и проверить доступ,
  восстановление и миграции. Совместимость определяется логическими
  данными приложения. QR-сопряжение и локальная синхронизация относятся
  к этапу 11.

## Сборка

Нужны JDK 17, Android SDK Platform 36 и Build Tools 35.0.0. Подготовить SDK и
прописать `ANDROID_HOME`, затем в папке `android/`:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

На телефоне или эмуляторе поддерживается Android 8.0 (API 26) и новее.
Проверочный пакет называется `ru.crown.finance.preview`. Результат сборки —
`android/app/build/outputs/apk/debug/app-debug.apk`. APK и SDK находятся
в локальных артефактах и в Git не включаются.

[Совместимость Android Gradle Plugin](https://developer.android.com/build/releases/agp-8-13-0-release-notes),
[Room](https://developer.android.com/jetpack/androidx/releases/room).
