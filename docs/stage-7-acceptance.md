# Ручная приёмка срезов этапа 7

План для dev46. Автоматические доказательства приводятся отдельно в отчётах
бюджета, средств на счетах и цели накоплений. Этот список не означает,
что ручные проверки уже пройдены.

Запускайте проверенный каталог через `artifacts/start-checked-ocr-dev46.cmd`,
когда он подготовлен. Создайте новую тестовую книгу и выберите для неё
свои тестовые парольную фразу и PF1. Готовой книги и пароля у комплекта нет.
Секреты и пользовательские финансовые файлы в чат не нужны.

## Одна книга для трёх новых отчётов

Создайте банковский, инвестиционный счета и счёт наличных без операций.
Добавьте категории расходов «Еда» и «Комиссии».

| Дата | Действие | Сумма, RUB |
|---|---|---:|
| 01.10.2026 | Начальная позиция банковского счёта | 1 000,00 |
| 02.10.2026 | Перевод с банковского на инвестиционный счёт | 300,00 |
| 02.10.2026 | Комиссия этого перевода, категория «Комиссии» | 1,00 |
| 31.10.2026 | Расход с банковского счёта, категория «Еда» | 100,00 |
| 01.11.2026 | Расход с банковского счёта, категория «Еда» | 200,00 |
| 02.11.2026 | Расход с банковского счёта, категория «Еда» | 500,00 |

Комиссия задаётся в форме перевода. В журнале получится пять операций.

### Бюджет по датам

1. «Отчёты → Бюджет расходов…»: выберите «По датам», 31.10–01.11.2026,
   лимит 500,00 RUB, банковский счёт и точную категорию «Еда».
2. Результат: расход 300,00 RUB, остаток по лимиту 200,00 RUB,
   две исходные операции.
3. Откройте исходную версию строки, затем вернитесь к результату
   и «К параметрам». Даты, отбор и лимит должны сохраниться.
4. Измените окончание на 31.10.2026. Результат: расход 100,00 RUB,
   остаток 400,00 RUB. При окончании раньше начала форма должна
   объяснить ошибку и позволить её исправить.
5. Проверьте режим календарного месяца: октябрь 2026 и категория «Еда»
   дают расход 100,00 RUB. Комиссия относится к другой категории.

### Средства на счетах

1. «Отчёты → Средства на счетах…»: дата 02.10.2026.
   Банковский счёт 699,00 RUB, инвестиционный 300,00 RUB,
   наличные 0,00 RUB. Общий итог — 999,00 RUB.
2. Выберите банковский счёт, откройте движения и версию перевода.
   Вернитесь к результату и «К дате расчёта».
3. Дата 31.10.2026: банковский счёт 599,00 RUB, инвестиционный
   300,00 RUB, общий итог 899,00 RUB.
4. Дата 02.11.2026: банковский счёт −101,00 RUB, инвестиционный
   300,00 RUB, общий итог 199,00 RUB. Отрицательный остаток виден со знаком.
   У наличных без движений кнопка источников недоступна.

### Цель накоплений

1. «Отчёты → Цель накоплений…»: дата 31.01.2026, накоплено 100,00 RUB,
   цель 300,00 RUB, пополнение 100,00 RUB в месяц, срок 30.03.2026.
2. Ожидается: остаток 200,00 RUB, прогресс 33,33%, первое пополнение
   28.02.2026, достижение 31.03.2026, сумма к сроку 200,00 RUB,
   нужное пополнение 200,00 RUB в месяц.
3. Вернитесь «К условиям». При сроке 31.03.2026 достаточно
   100,00 RUB в месяц. Суммы и дата расчёта должны сохраниться.
4. Выключите срок и задайте нулевое пополнение. При недостигнутой цели
   дата не рассчитывается, это объясняется в результате.
5. В журнале по-прежнему пять операций. Сценарий цели их не создаёт.

## Остальная ручная приёмка

| Проверка | Что подтвердить |
|---|---|
| Старт и навигация | До открытия книги рабочие разделы скрыты. Навигация слева; настройки последние. Отчёты и формы открываются в главном окне. |
| Клавиатура | Фокус внутри открытой формы; Escape последовательно возвращает назад, затем на кнопку исходного действия. |
| Открытие и PF1 | Новая тестовая книга сразу открывается после закрытия, без перезапуска. Полный PF1 автоматически выбирает восстановление. |
| Недавние книги | Тестовая книга появляется в недавних; выключение запоминания в её настройках убирает её из списка. |
| Копия и восстановление | Копия создаётся и проходит проверку, восстановление в новую папку сохраняет справочники и журнал; новая книга сразу повторно открывается. |
| Журнал | Разделение, связанные возвраты, исправление/история и закрытые месяцы сверяются по [инструкции Windows](windows-quickstart.md). Полная приёмка этапа 4 ещё не закрыта. |
| OCR | На локальных примерах сверяются карточка и история, строки, суммы/направления/даты, отсутствие бонусов в денежных доходах и выбранный режим подтверждений. Изображения остаются на ПК. |
| Бонусы | Программы и единицы бонусов отдельно от RUB; начисление по категории, списание, остаток и отчёт сверяются вручную. |
| Импорт и экспорт | Синтетические CSV/OFX повторно не создают движений; управляемый экспорт соответствует выбранному отбору. |
| Автономность | При отключённой сети работают книга, отчёты, локальный OCR и копии. Автоматические тесты сами по себе эту ручную проверку не заменяют. |
| Масштаб Windows | При 100/125/150% в настройках Windows видны поля, кнопки, таблицы и прокрутка; элементы доступны с клавиатуры. Масштабы процесса Qt проверяются отдельно автоматически. |
| Чистая Windows | Полный каталог приложения запускается без установки Python/uv, создаёт тестовую книгу, выполняет расчёты и локальный OCR. Подойдёт отдельная чистая Windows или Windows Sandbox. |

Подготовленные `.wsb` используют отключённую сеть/буфер обмена и доступ
к каталогу программы только для чтения. Формат конфигурации:
[документация Microsoft](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-configure-using-wsb-file).
Включение компонента Windows и ручная проверка гостевой среды выполняются
отдельно; наличие файла конфигурации не доказывает успешный запуск.

Для обратной связи достаточно версии, названия шага и «прошло» либо текста
ошибки без личных данных. Пароль, PF1 и файлы книги не присылайте.
