# ADR-0009: управляемый экспорт согласованного снимка журнала

Статус: принято для части требования 5.13 этапа 4, 27.10.2026.

1. Пользователь выбирает условия и состав, просматривает снимок, затем новое имя
   CSV/JSON. Книга не записывается; экспорт не заменяет полную зашифрованную копию.
2. Текущие принятые операции и названия читаются одной SQL-транзакцией под RLock.
   Снимок неизменяем, привязан к UUID открытой книги; поздние правки его не меняют.
   UUID привязки не сериализуется. Перевод, комиссия и части остаются целой операцией.
3. Используется существующий OperationQuery, включая виды/период/счета/категории.
   Удалённые версии включаются явно. Полной истории и иных наборов данных пока нет.
4. JSON v1 хранит минимальные единицы десятичными строками, валюту/точность отдельно.
   CSV UTF-8 BOM/`;`/CRLF имеет русские заголовки, читаемые суммы и точные минимальные
   единицы. Денежных float/округления нет. Состав: [контракт](../export-format-draft.md).
5. Названия включены по умолчанию, примечания/теги — нет. Исключение имён также
   убирает имена частей/тегов. Текст поиска, ключи/пароли из хранилища, raw-файлы,
   пути и внутренние квитанции не выгружаются. Сторонним сервисам ничего не отправляется.
6. Текст CSV защищён от формул, JSON сохраняет исходный выбранный текст. GUI показывает
   до 200 строк и общий состав; сохраняет всю выборку. Файл открыт, это явно показано.
7. Предлагается локальная AppData/PersonalFinance/exports. Запись внутри книги и
   замена существующего файла запрещены. Новое собственное временное имя, fsync
   и публикация без замены защищают от частичного/чужого назначения. Очистка
   выполняется только если временный файл действительно создан этим вызовом.
8. Журнальный CSV не является банковской выпиской со знаками движений. Банковский парсер
   отвергает его полную сигнатуру до сопоставления столбцов; отдельный общий заголовок
   «ID операции» у банка не блокируется. Это предотвращает неверное понимание
   положительных сумм расходов/переводов при повторном вводе.
9. Новых миграций нет: журнал экспортируется в 0003–0008. В 0002 функция недоступна.
   Форматы книги, ключей и копий неизменны. Полный экспорт прочих модулей и пакет
   ChatGPT остаются этапом 8; наличие локального файла не означает синхронизацию.
