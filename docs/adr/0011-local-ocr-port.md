# ADR-0011: граница локального OCR и прототип Tesseract

Дата: 27.10.2026. Статус: принят для первого технического среза этапа 5;
окончательная поставка движка зависит от качества, лицензий и чистой Windows.

OCR должен возвращать проверяемые черновики, не записывая деньги по распознанному
тексту. Системный Windows.Media.Ocr имеет дополнительный package identity/MSIX
контракт и зависит от языковых пакетов ОС. Изолированный CLI Tesseract допускает
проверку stdin/stdout и закрепление моделей без изменения согласованного стека.
Исследование и первичные источники: [план этапа](../stage-5-plan.md).

1. Domain задаёт неизменяемые изображения/слова/области/версию движка; application
   использует порт OcrEngine и проверяет принадлежность ответа входу. SQL/Qt/
   subprocess находятся вне domain. OCR API работает без открытой книги.
2. Загрузчик PNG/JPEG нормализует изображение в памяти. Ограничивает байты,
   геометрию и количество изображений, применяет EXIF-поворот. Метаданные
   исходника не передаются движку. Прозрачность отображается на белом фоне.
3. Прототип Tesseract требует явный runtime и хеши EXE/DLL/моделей. Нет поиска
   стороннего OCR в PATH и автоматического скачивания. Перед каждым запуском —
   проверка файлов. Движок получает PNG через stdin; TSV возвращает через stdout.
4. Процесс без shell с ограниченными временем и каналами. Содержимое изображений,
   текст и stderr не журналируются; ошибки не пересказывают ответ процесса.
   Это не sandbox нативного движка и не доказательство сетевого аудита ОС.
5. Слова сохраняют исходный текст, координаты и Decimal-оценку. TSV проверяется
   строго; ни одна замена похожих букв/цифр не выполняется молча. Оценка слова
   не является уверенностью в сумме/дате; адаптер проверяет поля отдельно.
6. Банковский адаптер, предпросмотр и подтверждение добавляются отдельным срезом.
   До него распознавание не имеет доступа к Ledger/Importing и не создаёт фактов.
   ImportKind.CSV/OFX не используется для маскировки изображения.
7. Runtime кандидата не включён в текущий EXE. Для поставки нужны полный
   лицензионный состав DLL/моделей, воспроизводимая подготовка и проверки чистой
   Windows/автономности. Форматы книги/ключей/копии этим срезом не меняются.

[Проверки и ограничения](../stage-5-ocr-report.md).


## Уточнение доставки 29.10.2026 — dev21

Для локального кандидата bootstrap принимает явный --ocr-runtime либо фиксированный
ocr-runtime рядом с frozen EXE. Доверенный манифест входит в ресурсы приложения;
внешний JSON не может разрешить иной набор файлов. Отсутствие модуля сохраняет
обычный запуск без OCR, ошибка подключения не блокирует книгу. Поиск в PATH/cwd
и автоматическое скачивание по-прежнему отсутствуют. Пункты 3/7 выше описывают
первый прототип; лицензии всех DLL/чистая Windows/автономность всё ещё необходимы
для окончательной поставки. [Проверки](../stage-5-frozen-ocr-report.md).
