# ADR-0013: настраиваемая проверка и атомарный список OCR

Дата: 28.10.2026. Статус: принято по прямым уточнениям пользователя в этапе 5.

## Контекст

Ручная проверка показала пропущенные однодесятичные суммы, отсутствующий год,
лишнюю галочку одной операции и последовательность окон для каждой строки.
Пользователь запросил отключаемые подтверждения, свои имена отправителей,
явные переводы между учитываемыми счетами, порядок страниц и контрастность.

## Решение

Сохранить raw OCR, предлагать год/валюту из настроек и проверять точные значения.
Убрать отдельную галочку одной операции; четыре флажка и итоговое окно сделать
отключаемыми. Создать редактируемый список 1–100 строк с одной атомарной записью,
сохраняя правки при отмене/ошибке. Свои отправители предлагают существующий TRANSFER
с двумя счетами либо явно исключают строку, без изменения прежних фактов.

Схема 0011 добавляет версии зашифрованных настроек/указатель и квитанции пакета/
его строки. Прежние SQL-защиты и финансовые хеши не переписываются. Имена не
попадают в QSettings. Переход старой книги — через копию в новую папку.

Нормализованный PNG имеет фиксированный DPI для независимости от QGuiApplication;
тот же исходный файл не импортируется повторно с другим входным хешем. Для
неполной поддержанной карточки разрешён один PSM 11 после PSM 6, целиком и без
потери/противоречия известных полей. Непроведённые и неоднозначные макеты не обходятся.

## Следствия

Обязательны проверки атомарности/повторов, копии/миграции, отключённых подтверждений,
масок, сохранения правок, правил имён, SVG в EXE и стабильности входа. Отключение
лишних действий не превращает предложения в достоверные банковские факты.
RUB остаётся единственной поддержанной валютой текущего финансового интерфейса.
Пакет не сохраняет черновики после закрытия; поставка OCR-runtime и полная
банковская разметка/ручная приёмка остаются незавершёнными.
