# ADR-0006: контрольная сверка без изменения журнала

Статус: принято для A1 в разрешённом этапе 4, 27.10.2026.

Сверка принимает счёт, календарную дату и контрольный остаток из выписки.
Остаток книги и принятые операции читаются в одной транзакции под общим RLock;
параллельная финансовая команда не может разорвать снимок. Домен сверяет сумму
движений с прочитанным остатком и возвращает линии, итог и разницу.

Разница определяется как «выписка минус книга». Каждый остаток — Money int64;
их разница может достигать ±2×MAX_MINOR и остаётся Python int, без записи в Money
и без float. Отображение общее с денежным форматированием, с целочисленным divmod.

Сверка не создаёт операции/отметки, не меняет счёт, журнал, квитанции или
последовательности. Она разрешена в закрытом месяце. Результат — разовый снимок;
после правок его нужно получить заново. В UI только RUB, как в текущем журнале.
Сохранение истории сверок и импорт строк выписки в эту поставку не включены.

Новой миграции нет: схема остаётся 0006. Сверка поддерживает все схемы с журналом
0003–0006; для неё восстановление старой книги не требуется. Форматы и финансовые
хеши не меняются. Доказательства: [отчёт сверки](../stage-4-reconciliation-report.md).
