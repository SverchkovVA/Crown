# План и факт годовой доходности вклада — dev115

В отчёте отдельного счёта видны рядом годовая доходность по сценарию и
доходность по журналу. Обе рассчитаны по датированным денежным потокам
с календарным годом из 365 дней. Суммы процентов и их источники остаются
в отчёте. Расчёт выполняется по выбранному срезу.

В прогнозе суммируются движения по условиям сценария, отдельные выплаты
и расчётный остаток на дату среза. Капитализированные проценты входят
в остаток один раз. Срез позже срока использует остаток и выплаты на
конец вклада. По журналу берутся зарегистрированные движения и остаток
отдельного счёта из того же снимка, что и фактические проценты.

Когда потоков недостаточно или их последовательность неоднозначна, для
соответствующей ставки отображается отсутствие расчёта. Для вклада,
по которому проценты зачисляются на другой счёт, связь с отдельными
выплатами пока не предусмотрена. Хранение и схема 0018 не меняются.

Локально прошли 168 связанных проверок и визуальная проверка Qt Windows в
двух темах на 100%, 125% и 150%. В примере на один год по журналу показаны
10,00%, по сценарию 36,50%. Из отчёта открывается неизменяемая версия движения.

Для ручной проверки в учебной книге создайте отдельный счёт вклада.
Запишите 1 000,00 RUB в день открытия и 100,00 RUB процентов через 365 дней.
Сохраните сценарий на год со ставкой 36,5% и выплатой в конце. В «Плане и факте»
выберите счёт, категорию процентов, конечную дату и расчёт отдельного вклада.
Проверьте обе ставки и строки источников.
