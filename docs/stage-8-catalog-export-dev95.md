# Локальный экспорт справочников

В «Отчёты → Аналитика → Экспорт справочников…» выбираются банки, счета
и категории. Можно сохранить один или несколько справочников в CSV
или JSON. По умолчанию названия исключены. Номер счёта, связь счёта
с банком и связь категории с родителем действуют внутри файла.
Связь отображается, когда её целевой справочник выбран. UUID книги,
операции, остатки и секреты не выгружаются.

Предпросмотр показывает первые 200 строк. Выбранный файл содержит
все строки того же снимка. В CSV имена с формулами экранируются,
используются UTF-8 BOM и разделитель «;». JSON содержит технические
значения типа. Файлы создаются отдельно от книги. Схема 0017 прежняя,
справочники старых книг доступны без миграции.

На новой учебной книге заведите банк, счёт этого банка, категорию
и подкатегорию. Проверьте связи при выгрузке всех справочников,
затем оставьте только счета. Сохраните один файл с выключенными
названиями и другой с включёнными. Сравните с предпросмотром.

Исходник 0850a670b5afebaa7d3c247a6dcdbd540bb9c617. Прошли 22 связанные
проверки, в том числе экспорт из учебной книги схемы 0002. В сценарии
навигации теперь проверяется встроенный экран состава копии. Для
полного Linux-прогона после повторных тайм-аутов задано 70 минут;
90-секундный сторож отдельного зависшего теста сохранён.

Сборка Windows и нативные самопроверки исходников и EXE по 34 шага
прошли. Точный EXE запустился в чистой Windows Sandbox без сети, Python
и uv. Предпросмотр справочников и бонусов проверен в обеих темах
при 100%, 125% и 150%. Первое измерение бонусной формы на 150%
попало на обновление разметки. Повтор после её стабилизации подтвердил
кнопку, таблицу и отсутствие горизонтальной прокрутки.
