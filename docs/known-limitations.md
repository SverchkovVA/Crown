# Известные ограничения

1. Проверочная версия, не для реальных финансов. Полная приёмка Windows 11 ещё не завершена.
2. Нет финансовых операций, начальных остатков и денежных балансов. Справочники
   не показывают фиктивные суммы.
3. Нет редактирования/архивирования счетов и категорий. Созданные записи сохраняются.
4. Нет OCR, файлового импорта, экспортов, вкладов, аналитики, планов и инвестиций.
5. Резервирование ручное. Нет расписания, ротации, автоблокировки и смены пароля.
6. Восстановление только в новую папку, без замены текущих данных. Схема копии
   должна соответствовать текущей версии. Размер базы ограничен 10 GiB.
7. Неизвестная/старая схема не обновляется автоматически. Безопасное обновление
   опубликованных пользовательских версий предстоит реализовать до его необходимости.
8. Нет синхронизации. Таблицы версий и журнала не означают готовый сетевой протокол.
9. Нет DPAPI, аппаратного хранилища Android и гарантированного обнуления Python RAM.
10. Модель защищает закрытые файлы, но не открытое приложение от вредоносного кода
    с правами пользователя.
11. Полный сетевой аудит и реальные отключения питания не проводились. Тест
    завершения процесса покрывает другой класс аварий.
12. Нет NSIS-установщика, подписи и проверки полного лицензирования дистрибутива.
13. Проект опубликован в SverchkovVA/Crown. Результаты фактических прогонов CI
    и оставшиеся проверки приведены в docs/stage-3-report.md.
14. Сценарий Windows и отчёты добавлены в 0.1.1. Проверка их помощников в
    PowerShell на Linux не означает работоспособность приложения на Windows.

Эти ограничения не снимают обязательства конечного плана.
