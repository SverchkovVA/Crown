# Известные ограничения

1. Проверочная версия, не для реальных финансов. Полная приёмка Windows 11 ещё не завершена.
2. В 0.2.0.dev6 есть ручной журнал, начальные остатки, остатки на дату,
   разделение, возвраты, закрытие месяцев, сверка, теги и сохранённые фильтры. Нет
   импорта и финансовых отчётов. Полный этап 4 ещё не принят.
3. Нет редактирования/архивирования счетов и категорий. Созданные записи сохраняются.
4. Нет OCR, файлового импорта, экспортов, вкладов, аналитики, планов и инвестиций.
5. Резервирование ручное. Нет расписания, ротации, автоблокировки и смены пароля.
6. Восстановление только в новую папку, без замены текущих данных. Поддерживаются
   схемы 0002/0003/0004/0005/0006/0007; копия 0002/0003/0004/0005/0006 обновляется до 0007 при восстановлении. Размер базы
   ограничен 10 GiB. Понижение версии схемы не поддерживается.
7. Исходные старые книги не мигрируются при открытии. Для журнала из 0002
   или разделения из 0003, возвратов из 0004, закрытия периодов из 0005, тегов/сохранённых фильтров из 0006 нужен переход через копию и восстановление в новую папку. Неизвестная схема
   отклоняется. Не смешивайте восстановленную и исходную книгу при ручной работе.
8. Нет синхронизации. Таблицы версий и журнала не означают готовый сетевой протокол.
9. Нет DPAPI, аппаратного хранилища Android и гарантированного обнуления Python RAM.
10. Модель защищает закрытые файлы, но не открытое приложение от вредоносного кода
    с правами пользователя.
11. Полный сетевой аудит и реальные отключения питания не проводились. Тест
    завершения процесса покрывает другой класс аварий.
12. Нет NSIS-установщика, подписи и проверки полного лицензирования дистрибутива.
13. Проект опубликован в SverchkovVA/Crown. Результаты фактических прогонов CI
    и оставшиеся проверки приведены в docs/stage-3-report.md.
14. Сценарий Windows и отчёты добавлены в 0.1.1. Проверка их помощников в
    PowerShell на Linux не означает работоспособность приложения на Windows.

15. В одном ручном сценарии PF1 не включил режим автоматически, но открыл книгу
    после ручного включения флажка. Синтетические проверки клавиатурного ввода
    и вставки проходят; причина ручного результата ещё не установлена.

16. Возвраты связаны только с расходом, включая его части; отдельного возврата
    комиссии перевода и автоматического подбора покупки нет. Пересчёт остатка
    выполняется при чтении журнала; нагрузка на большой журнал ещё не измерена.

17. Закрытие действует на календарный месяц всей книги. Произвольные диапазоны,
    автоматическое закрытие и контроль входящих сетевых изменений не реализованы.

18. Сверка — разовое сравнение с введённым остатком, в UI только RUB. История
    сверок и отметки отдельных строк не сохраняются. Импорта выписки и поиска
    различающихся банковских строк нет; сумму пользователь вводит самостоятельно.

19. Теги и сохранённые фильтры переносимы через копию, но сетевой синхронизации
    ещё нет. Фильтр показывает целую операцию, включая перевод и его комиссию;
    это не отдельный аналитический расчёт по части выбранных категорий.

Эти ограничения не снимают обязательства конечного плана.
