# Соседние подписи сводных показателей — dev54

06.11.2026. Продолжение OCR в отдельном worktree от805ea19/dev53.
Схема0014, модели/стек/криптографические форматы сохраняются.
Dev53 уточнила подпись с суммой в одной строке; новая синтетическая геометрия
показала ещё два ложных кандидата при подписи выше/ниже значения.

Решение: заранее вычислять индексы сводных строк по физической геометрии.
Одиночная сумма без собственного описания связывается только с отдельной
известной подписью итога в близкой строке и той же колонке. Нужны ограниченный
вертикальный промежуток и существенное пересечение горизонтальных областей.
Далёкая или чужая колонка не исключает сумму.

Название получателя перед настоящей суммой главнее следующей подписи
категории. Явные получатель/отправитель/описание поддерживают это решение.
«Списано»/«Зачислено» остаются полями движения, не итогами.
Сводный заголовок не подставляется вместо получателя.
Предварительный расчёт за один проход; не искать строку через list.index
при каждом обращении. Исходный документ и координаты не меняются.

Проверить карточку/историю, подпись выше/ниже, расстояние/колонку,
получателя и категории, реальные поля движения, смешанный список и аудит.
